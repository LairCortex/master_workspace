# Lucide-pass 2026-09-30: окна чар-листов и диалоги (тёмная тема)

Точка: живая пиксельная сверка Lucide-глифов в окнах листов чар-листов и в
диалогах (чек-поинты 1–8). Запуск `python dev_run.py` (PID 81405), игра
`qa-2026-09-30`, тема тёмная (дефолт ui.json). Светлая тема не включалась:
ни один глиф не требовал сверки контраста (все тинты идут из токенов skin,
контрастных в обеих темах). Ассеты: `docs/qa/assets/2026-09-30-lucide-pass-sheets-dialogs/`.

пикселями, кроме трёх рядов панели свойств, куда не достаёт синтетический

## Находки

### F-1 · minor · layout (не иконка)
- **Location:** окно «Типы событий», строка-подсказка над списком типов.
- **Evidence:** `06-event-types-full.png` + zoom (1045,562)-(1500,585).
- **Issue:** текст «Цвет — готовый образец палитры; удаление лишь отвязывает
  тип от событий» обрезан по правому краю листа многоточием на «…тип от …» —
  подсказка теряет смысл именно в той части, которая объясняет безопасное
  удаление.
- **Файл-подозрение:** `app/presentation/qml/EventTypesRoot.qml:96` (Text без
  wrapMode/min-width, ширина листа фиксирована).
- **Recommendation:** `wrapMode: Text.WordWrap` (или ElideRight с тултипом),
  либо расширить лист worst-case строкой.

### S-1 · suggestion · consistency
- **Location:** редактор листа, правая панель, кнопки «На передний план» /
  «На задний план».
- **Evidence:** живьём при 1280pt подписи целые (`02-editor-full.png`); в
  оффскрин-ренде при 1100pt — «На передний пл…» (`09-offscreen-editor-options-panel.png`).
- **Issue:** на суженной панели кнопки уходят в эллинг; решение «без иконок»
  (по замеру) не оставляет запасного канала. Unused `bring-to-front.svg` /
  `send-to-back.svg` уже лежат в `qml/nri/components/icons/`.
- **Recommendation:** либо min-width панели, либо вернуть глифы при тесноте.
  Дефекта на штатной ширине нет — только предложение.

### OBS-1 · наблюдение среды (не дефект приложения)
Синтетический ввод этого окружения не управляет холстом листа:
- координатные clicks (в т.ч. после activate_app) не доходят до `MouseArea`
  холста и до ряда кнопок страниц редактора (проверено повторными попаданиями
  по точным координатам — «Отменить» остаётся disabled, «Страница 2» не
  появляется); правый клик по «+» таймлайна при этом доходит (меню открылось),
  и клик по нативному попапу меню сработал;
- `AXPress` по кнопкам-инструментам палитры лишь визуально ставит галочку,
  не дёргая `vm.set_tool` (в дереве одновременно `Указатель=1` и `Картинка=1`)
  — тот же класс, что FI/F2ThemeCheckBox из UX-чека 1 (2026-09-30,
  `docs/qa/2026-09-30-lucide-pass-main-window.md`);
- попап `ThemeComboBox` (MenuButton) не открывается ни AXPress-ом, ни
  координатами.
Следствие: ряды 2e/3-картинка закрыты оффскрин-рендом реальных QML-корней
(те же токены/компоненты, `QT_QPA_PLATFORM=offscreen`, временный тест удалён
после прогона), а 4c — кодом (`ThemeComboBox.qml:196`) + живым дейт-пикером.
