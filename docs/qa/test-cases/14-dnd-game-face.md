## Пробелы (не нормировано спеками — фиксируется, не выдумывается)

1. **Формулировка пометки «источник не подключён»** в полях таба «D&D»/«Заклинания» и в справочных поверхностях — нормирован факт пометки, текст свободен (DCEX-005/007, DREF-008).
2. **Шаблон адреса листа LSS** для кнопки «Открыть в браузере» вне самого идентификатора не зафиксирован (DCEX-004).
3. **Тексты подтверждений** (перезапись персонажа из файла, замена гримуара) — нормирован только факт подтверждения, формулировки свободны (DCIM-001, DGRI-002).
4. **Правило фильтра справочного листа** (регистронезависимость, подстрока против префикса) не нормировано — кейс исходит из «фильтр по подстроке имени» сценария, регистр не проверен (DREF-006).
5. **Допустимые значения количества в редакторе встречи** (0? отрицательные? максимум?) не нормированы — кейс фиксирует только штатный ввод (DENC-001).
6. **Точная форма отказа сохранения при уровне вне 1…20** (гейт контрола против сообщения при сохранении) не зафиксирована (DCEX-003).
7. **Состав групп табов и вид пометки лестницы** явно переданы дизайн-задаче спеками — визуальные ожидания приёмкой не связаны; кейсы проверяют только поведение и инварианты (CTAB, DENC-004, TLND-001).
