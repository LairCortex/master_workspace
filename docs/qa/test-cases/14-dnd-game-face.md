## external-entity-sources (EXTS)

### TC-EXTS-001 — Включённый модуль появляется во всех поверхностях

- Требование: Ядро принимает внешние типы через единый механизм источников
- Сценарий: Включённый модуль появляется во всех поверхностях
- Тип: положительный
- Приоритет: P0
- Статус: уточни
- Предусловия: D&D-игра `qa-<дата>`, подключён SRD-набор; игра открыта.
- Шаги: 1) глобальный поиск — запрос совпадает с названием справочной записи 2) поле `@` в тексте события — попавер 3) клик по строке поиска — предпросмотр 4) закрепить карточку 5) открыть карточку события — табы 6) событие со встречей — лестница
- Ожидаемый результат: записи источника доступны в поиске, попавере, предпросмотре, закреплениях; добавочные табы видны в карточках; пометки строк лестницы видны
- Источник: openspec/specs/external-entity-sources/spec.md#Ядро принимает внешние типы через единый механизм источников
