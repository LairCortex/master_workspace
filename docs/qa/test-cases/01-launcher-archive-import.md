### TC-LNCH-001 — Содержимое лаунчера — QML-островок в системной рамке

- Требование: Requirement: Поверхность лаунчера — QML-островок
- Сценарий: Scenario: Лаунчер поднят на QML
- Тип: положительный
- Приоритет: P1
- Статус: уточни
- Предусловия: приложение не запущено
- Шаги: 1) запустить `python -m app.main` 2) осмотреть открывшийся диалог выбора игры: рамку, заголовок-приглашение, список игр, кнопки «Новая игра», «Импорт», «Удалить», «Открыть», переключатель темы 3) закрыть диалог по Esc

- Живая проверка: аудит 2026-09-25 «launcher-quick-qa» (отчёт архивирован) §Покрытие 1,4 + «Что проверено и чистое» — `screenshot` окна + `zoom` 2 px/pt: перекрываний нет, текст читаем, протечек палитры OS вокруг острова нет; повторный запуск даёт идентичную раскладку
- Источник: openspec/specs/game-launcher/spec.md#Requirement: Поверхность лаунчера — QML-островок
