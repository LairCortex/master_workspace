# 11 — Доступность QML-островов (A11Y)

Источники: норматив — `openspec/specs/qml-accessibility/spec.md`; контекст формулировок
живых проверок и шесть зафиксированных пределов координатности — раздел
«Accessibility tree contract» в `AGENTS.md` и отчёты `аудит 2026-09-25 «accessibility-audit» (отчёт архивирован)`,
`аудит 2026-09-23 «accessibility-audit» (отчёт архивирован)` (новые требования из них не выводятся).

## Как проверять

Запуск: `python -m app.main` (или `python dev_run.py`). Изоляция: одноразовая игра
`qa-<дата>`, кнопки генерации ИИ не нажимать, завершение `pkill -if "app.main"`.
Инструменты чтения дерева: дерево доступности macOS — `get_app_state` (computer-use,
по element id), сырое AX-чтение (`AXRole`/`AXDescription`); оффскрин — QAccessible-тест
(`QT_QPA_PLATFORM=offscreen python -m pytest tests/presentation -k accessibility`).
Пресс из дерева: AXPress по element id / `doAction("Press")`; ошибка пресса не доказывает
промах — после ошибки перечитать дерево до повтора.

**Пределы харнесса живых Press-процедур (не дефекты продукта; искажают любой живой прогон —
`аудит 2026-10-01 «modal-sheets» (отчёт архивирован)` §Пределы харнесса H1/H2):**

- **H1 — синтетические координатные клики долетают не до всех целей.** Фоновый
  координатный клик computer-use («in background») может не дать ровно никакого эффекта в
  контент виджетных SheetFrame-листов (чекбокс посадки, «Закрыть», «Открыть стол») и в
  контролы QML-островов (чекбокс темы, чипы), тогда как AXPress по element id тех же
  элементов работает и клавиатура долетает. Порядок для любой живой Press-проверки:
  1) нацелить действие через доступность (AXPress по element id / `doAction("Press")`);
  2) если нужен именно клик — реальный клик мышью (CGEventPost с поднятием окна), не
  синтетическая фоновая координата; 3) молчание синтетического клика дефектом НЕ считать и
  оформлять дефект только после того, как канал доступа (пресс либо реальная мышь) тоже не
  отработал.
- **H2 — AX-рамки текстовых полей QML-островов проецируются с неверным экранным
  положением.** Координатный клик/наведение по element_id поля-острова уезжает в чужое место
  прогона (поле «Поиск»: клик прилетел в (1610,381) вместо (1000,128)) — для островных
  полей работают только press-действия и `type_text(element_id=…)` (последний иногда тоже
  мимо); перед набором текста фокус и целимость подтверждать скриншотом, а «не дошедшие»
  клавиатурные попытки сначала объяснять этим смещением, а не приложением.

### TC-A11Y-001 — Строка списка опознаваема

- Требование: Дерево доступности содержит каждый интерактивный элемент
- Сценарий: Строка списка опознаваема
- Тип: положительный
- Приоритет: P1
- Статус: уточни
- Предусловия: в каталоге есть игра «Игровка» с датой 01.01; открыт лаунчер
- Шаги: 1) снять дерево лаунчера (`get_app_state`) 2) найти строку игры по имени 3) указать её как цель действия без координат экрана

- Источник: openspec/specs/qml-accessibility/spec.md#Дерево доступности содержит каждый интерактивный элемент
- Живая проверка: аудит 2026-09-23 «accessibility-audit» (отчёт архивирован) §лаунчер + аудит 2026-09-25 «accessibility-audit» (отчёт архивирован) §1 — `get_app_state` лаунчера: строки каталога адресуются по полному имени «<игра> (<дата>)» (`query` по имени даёт совпадение), пресс по element id выполняет действие строки.

- Ожидаемый результат: либо роль строки доходит как пункт списка, либо потеря названа в списке пределов (предел ⑤) и адресность с AXPress работают — молчаливого расхождения «в коде роль есть, в дереве другое» нет
- Источник: openspec/specs/qml-accessibility/spec.md#Расхождение проекции роли не остаётся молчаливым
- Живая проверка: аудит 2026-09-25 «accessibility-audit» (отчёт архивирован) §«Оффскрин»/§«Живой прогон»/§«Минимальная проба починки» — оффскрин `queryAccessibleInterface(row).role()` = ListItem; сырое AX-чтение (`System Events`, raw `AXRole` у children окна) отдаёт `AXStaticText` рядом корректно доходящих `AXButton`/`AXCheckBox`; проба пяти ролей на одном Qt-билде показывает, что из `ListItem`/`Cell`/`Row`/`List`/`Button` теряется только ListItem — переизобретение роли на usage-site запрещён, молчаливого расхождения нет, только именованный предел ⑤ с перезафиксированным AXPress.

### TC-A11Y-034 — Описание строки лаунчера доходит до raw-программы

- Требование: Строки носят описание скрытого действия
- Сценарий: Описание доходит до программы
- Тип: положительный
- Приоритет: P1
- Статус: уточни
- Предусловия: открыт лаунчер со строками каталога
- Шаги: 1) raw-инспектором (`AXDescription`, сырое AX-чтение) прочитать описание строки игры 2) перечитать то же дерево терминальным обзором (`get_app_state`)
- Ожидаемый результат: описание «Открывает игру» получено независимо от того, показывает ли его терминальный инструмент; не displaying описания обзором не оформляется дефектом
- Источник: openspec/specs/qml-accessibility/spec.md#Строки носят описание скрытого действия
- Живая проверка: аудит 2026-09-25 «accessibility-audit» (отчёт архивирован) §1 — сырое чтение `AXUIElementCopyAttributeValue` (CoreFoundation через ctypes) отдаёт «Открывает игру» на каждой строке каталога; `get_app_state` рисует имя без описания — это не дефект; обход `System Events` по островам нечитаем, raw-путь единственный воспроизводимый.

### TC-A11Y-035 — Селектор часа «Сейчас» адресен и назван; его список — отдельное окно

- Требование: Дерево доступности содержит каждый интерактивный элемент
- Сценарий: производный из требования
- Тип: положительный
- Приоритет: P2
- Статус: вывед
- Предусловия: открыто главное окно с виджетом «Сейчас» в шапке поиска
- Шаги: 1) снять дерево (`get_app_state`, `query` по «Час») 2) прочитать роль и имя селектора часов 3) послать пресс и перечитать список окон 4) снять дерево раскрытого списка часов
- Ожидаемый результат: селектор адресен и именован («Час сейчас»); пресс открывает список часов, который приходит отдельным окном — его строки не узлы острова (предел ③), триггер при этом остаётся именованным и адресным
- Источник: openspec/specs/qml-accessibility/spec.md#Дерево доступности содержит каждый интерактивный элемент
- Живая проверка: аудит 2026-09-29 «now-hour-chip-fixes» (отчёт архивирован) «до-фикс хоста и повтор» + аудит 2026-09-29 «now-hour-chip-design» (отчёт архивирован) «Доступность имени» — имя «Час сейчас» адресно в дереве; список открывается вне хоста острова отдельным окном полной высоты (8 строк); AX-пресс триггера с фоновой доставкой может не долететь (OBS-1) — раскрытие проверять реальным кликом.
