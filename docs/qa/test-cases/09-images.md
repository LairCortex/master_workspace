# 09 — Изображения: хранилище и отображение (IMGS / IMGD)

Источники:
- openspec/specs/image-storage/spec.md
- openspec/specs/image-display/spec.md

Общие предусловия (ОП): запуск `python -m app.main`; создана одноразовая игра `qa-2026-10-03`; в отдельной папке подготовлены образцы: читаемые PNG/JPEG, файл 4000×3000, нечитаемый файл (текстовый, переименованный в .png), копия legacy-игры (снимок из старой версии приложения с base64-картинками и/или без колонки картинки предмета). Кнопки генерации ИИ не нажимать. Завершение набора: `pkill -if "app.main"`. Терминал (`ls`, `shasum -a 256`, `sqlite3` только на чтение) применяется лишь там, где спека прямо задаёт факт о диске/базе (sha256, путь, содержимое таблицы `images`).

## Пробелы

- G1. Набор читаемых/поддерживаемых форматов изображений спекой не перечислен (задания только поведение «нечитаемый → ошибка»).
- G2. Поведение preview для оригиналов с максимальной стороной ≤ 512px (масштабировать вверх / копировать / пропускать) не задано.
- G3. Способ QA-подтверждения детерминированности пересоздания preview (байтовое совпадение с прежним) не определён.
- G4. Тексты сообщения об ошибке нечитаемого файла (карточка сущности, поле шаблона, Fill, веб-Fill) не заданы.
- G5. Формулировка предупреждения в отчёте xlsx-импорта о строке с нечитаемым файлом не задана.
- G6. Способ подтверждения VACUUM-упаковки базы в запуске миграции не определён (косвенный признак — уменьшение файла `game.db` — спекой не закреплён).
- G7. Точка ввода «произвольного URL из интернета» в интерфейсе игрока не определена — запрет сохранения URL (TC-IMGS-043) руками непроверяем.
- G8. Текст «сообщения об отсутствии оригинала» при клике без оригинала и preview не задан.
- G9. Формат/текст записи в логе об ошибке физического удаления файла не задан.
- G10. Способ подтверждения «пустой плейсхолдер не ссылается» и «в JSON макета нет пути» (внутреннее состояние поля шаблона) не определён.
- G11. image-display обещает не удалять ссылку в базе при недоступном файле, а startup-сканирование image-storage удаляет запись без оригинала и обнуляет ссылки — нужно уточнить ожидаемое состояние таких мест после перезахода в игру.
- G12. Способ подтверждения «показ не входит во вложенный цикл событий» (просмотр оригинала) не определён.
