# 03 — События и лента времени

Источники: openspec/specs/event-timeline/spec.md, openspec/specs/event-subevents/spec.md, openspec/specs/event-time/spec.md, openspec/specs/event-types/spec.md

Общее предусловие (в кейсах не повторяется): приложение запущено `python -m app.main`; изоляция по соглашению репозитория — одноразовая игра `qa-<дата>`, кнопки генерации ИИ не нажимать, завершение `pkill -if "app.main"`. Событие создаётся/редактируется через карточку события (двойной клик по строке ленты).

## event-timeline (TC-TLNE)

### TC-TLNE-001 — Даты строк и чипа окна по игровому календарю

- Требование: Лента времени и даты
- Сценарий: Игровые месяцы
- Тип: положительный
- Приоритет: P1
- Статус: уточни
- Предусловия: в настройках календаря игры заданы кастомные названия месяцев; в игре есть событие.
- Шаги: 1) Открыть главное окно, посмотреть дату в строке события на ленте. 2) Задать окно фильтра «Выбор даты» и прочитать подпись кнопки.
- Ожидаемый результат: и строка события, и подпись кнопки «Выбор даты» используют кастомные названия месяцев игры, а не ISO-месяцы.
- Источник: openspec/specs/event-timeline/spec.md#Лента времени и даты

- Предусловия: лист «Типы событий» открыт.
- Шаги: 1) Сверить строку заголовка: название «Типы событий» и кнопка «Закрыть». 2) Переименовать тип. 3) Нажать «Закрыть». 4) Открыть лист заново. 5) Повторно переименовать тип и закрыть лист клавишей Esc.
- Ожидаемый результат: лист закрывается и по кнопке, и по Esc; подтверждения нет; переименование осталось применённым в обоих случаях.
