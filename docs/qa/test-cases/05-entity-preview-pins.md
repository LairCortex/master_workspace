# 05 — Предпросмотр сущностей и закрепления (PREV, PINS)

Источники: openspec/specs/entity-preview/spec.md, openspec/specs/preview-pins/spec.md

Общие предусловия (не повторяются в кейсах): запуск `python -m app.main`, одноразовая игра `qa-<дата>`, кнопки генерации ИИ не нажимать; «средний столбец» — панель сущностей главного окна, «правая колонка» — колонка предпросмотра.

## entity-preview (PREV)

### TC-PREV-001 — Персонаж показан целиком, только для чтения

- Требование: Состав читаемого предпросмотра — полные поля карточки
- Сценарий: Персонаж показан целиком
- Тип: положительный
- Приоритет: P0
- Статус: уточни
- Предусловия: создан персонаж с заполненными названием, рейтингом, датами начала/конца, «Характеристиками», «Предысторией», «Личностью», «Задачами» и ссылкой на музыку.
- Шаги: 1) выбрать строку персонажа в среднем столбце 2) прочитать правую колонку 3) попытаться редактировать любое поле и поискать в карточке кнопки сохранения/генерации/правки.
- Ожидаемый результат: видны название, рейтинг, даты с возрастной строкой, «Характеристики», «Предыстория», «Личность», «Задачи» и ссылка на музыку; ни одно поле нельзя отредактировать; кнопок сохранения, генерации и правки в предпросмотре нет.
- Живая проверка: аудит 2026-09-27 «nri-0022-entity-preview-island» (отчёт архивирован) §Вердикты 2,6 — выбор строки AXPress (тот же канал выбора); «zoom» читает все секции с 13-px подписями без элизий; в предпросмотре нет ни одной кнопки правки; строка средней колонки получает accent-подсветку
- Живая проверка: docs/functional-checklist.md §карточка/снимок — цвет фона рейтинга ⏳ не подтверждён живьём с прогонов 2026-08-22 (оффскрин-приёмка цветов не покрывает; та же половина открыта у карточки — app-map F07). Процедура: выбрать сущность с высоким рейтингом, `zoom` 2 px/pt полосу рейтинга живой карточки, затем закрепить её карточку и `zoom` её же в pane-е банка пинов; переключить «Светлая тема» и повторить оба зума. Ожидаемое наблюдаемое: тонировка рейтинга серый→красный по токенам читается в обеих темах, подпись «N/20» поверх тонировки различима.
- Источник: openspec/specs/entity-preview/spec.md#Requirement: Состав читаемого предпросмотра — полные поля карточки

### TC-PREV-005 — Картинка занимает четверть полосы и масштабируется с колонкой

- Требование: Состав читаемого предпросмотра — полные поля карточки
- Сценарий: Картинка — четверть полосы и растёт с колонкой
- Тип: граница
- Приоритет: P2
- Статус: уточни
- Предусловия: сущность с изображением показана в предпросмотре.
- Шаги: 1) оценить ширину картинки относительно верхней полосы 2) расширить и сузить колонку разделителем, наблюдая за картинкой 3) в узком слоте посмотреть плейсхолдер «Нет изображения» у сущности без картинки.
- Ожидаемый результат: картинка занимает четверть ширины верхней полосы и масштабируется вместе с шириной колонки, оставаясь четвертью (при ширинах полосы 420/720 px картинка 105/180 px ±1 — оффскрин-параметризация), высота относится к ширине как 4:3; в узком слоте плейсхолдер показывает только глиф — подпись «Нет изображения» прячется, когда не вмещается, и не залезает на колонку полей.
- Живая проверка: аудит 2026-09-28 «entity-preview-half-picture» (отчёт архивирован) — точные pt через raw `AXPosition/AXSize` эпохи половины (блок = `AXButton` с описанием «Открыть изображение», полоса = `AXSize.width` строки связи с описанием «Переходит к сущность»; при ширинах окна 1100/1400/1900/2560 блок 217/279/381/517 pt — тогда ровно половина, h/w = 4:3; ручку QSplitter фоновый ввод не двигает — ширину колонки менять ресайзом окна). Срез доли до четверти внесён 2026-10-05 — живые числа половины больше не норма, требуется пересъёмка вживую: на четверти ширины полосы с точностью округления и тем же методом (raw-замер, h/w = 4:3); оффскрин-пин четверти и глиф-плейсхолдера — `tests/presentation/test_entity_preview_island.py`
- Источник: openspec/specs/entity-preview/spec.md#Requirement: Состав читаемого предпросмотра — полные поля карточки
