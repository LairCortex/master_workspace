# 15 — D&D-генерация для LSS: круг валидатора, датасеты, гримуары, персонажи, экспорт

Источники (дельта изменения `add-dnd-lss-generation` заархивирована 2026-10-12; нормы влиты
в сводные спеки — прицельно по изменению смотрят их версии в
`openspec/changes/archive/2026-10-12-add-dnd-lss-generation/specs/`):
`openspec/specs/dnd-generation/spec.md`,
`openspec/specs/dnd-character-export/spec.md`.

Аббревиатуры ID: dnd-generation (GENR), dnd-character-export (CEXP) — новые спецификации,
с конфликтов с прежними префиксами нет.

Общие предусловия (по своду правил `README.md`): `python -m app.main`, одноразовая игра
`qa-<дата>` c системой «D&D» и включённым модулем (файл 13, LNCHD-001), завершение
`pkill -if "app.main"`. Профиль «без модуля» — `NRI_DISABLE_DD_MODULE=1`. Глобальные
хранилища: датасеты — `~/.nri_manager/datasets/`, гримуары — `~/.nri_manager/grimoires/`;
живой прогон acceptance-кейсов пишет в них и подключает файлы к игре — после проверок
удалите добавленное вручную. В отличие от прежних файлов, этот набор требует настроенного
LLM («О приложении → Настройка LLM…»: base_url + модель): живые генерационные кейсы
выполняются только с рабочим OpenAI-совместимым эндпоинтом (локальный сервер — предпочтительнее,
свой ключ/квоты мастера). Оффскрин-контур (`QT_QPA_PLATFORM=offscreen python run_tests_isolated.py`)
пинит все эти нормы на `httpx.MockTransport` — живой прогон подтверждает формулировки и порядок
кнопок, а не сам канал. Кнопки генерации без настроенного сервера не нажимать.
Форматные проверки файлов (`character.jsonType`, `version: "2"`, конверт Foundry Item) —
чтение сохранённых файлов утилитой по выбору мастера; свод правил разрешает терминал там,
где спека фиксирует сам факт содержимого файла.

## dnd-generation (GENR)

### TC-GENR-001 — Второй круг исправил документ

- Требование: Круг генерации с обратной связью валидатора
- Сценарий: Второй круг исправил документ
- Тип: положительный
- Приоритет: P1
- Статус: уточни
- Предусловия: игра `qa-<дата>`, LLM настроен и готов, описание мира задано; лист «Датасеты D&D…» → «Сгенерировать ИИ».
- Шаги: 1) отметить одну секцию, идея сформулирована так, что первый ответ с высокой вероятностью содержит ошибку (например, ссылка на вымышленный идентификатор) 2) «Запустить» 3) дождаться завершения кругов
- Ожидаемый результат: круг завершился без ручного вмешательства; предпросмотр показывает валидный документ; отчёт — только предупреждения или «Замечаний нет»; кнопка «Принять» доступна
- Источник: openspec/specs/dnd-generation/spec.md#Круг генерации с обратной связью валидатора
