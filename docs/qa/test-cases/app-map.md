# Карта приложения: экраны, окна, флоу, точки UI/UX-проверок

Источник истины по нормам окон и колонок — `AGENTS.md` (разделы «Window-class norm»,
«Main-window columns», «Event nesting and the game day size», «GUI verification on a
real display»); требования — `openspec/specs/<домен>/spec.md`; живые проверки —
`docs/qa/*.md`; ручные кейсы — `docs/qa/test-cases/01…12-*.md` (префиксы ID — в
`docs/qa/test-cases/README.md`). Ничего не выдумано: неподтверждённое помечено
**«проверить вживую»**.

Общая команда запуска: `python -m app.main` (на macOS для корректной подписи процесса —
`python dev_run.py`). Изоляция по соглашению репозитория: одноразовая игра `qa-<дата>`,
кнопки генерации ИИ не нажимать, завершение — `pkill -if "app.main"`.

## 1. Классы окон

Норма — `AGENTS.md` § «Window-class norm» (change `nri-0024-modal-sheets-contract`,
capability `modal-sheets`): каждый экран принадлежит ровно одному классу, формат окна
никогда не зависит от случайности вызова. Три класса: два нелистовых экрана, листы
(всё остальное содержимое) и фиксированные исключения. Контракт показа листа:
`QDialog(parent=MainWindow)` + `open()` (WindowModal); QML-содержимое — через
`IslandDialogMixin` + `ThemeSheetHeader` (шапка «заголовок + Закрыть», заголовок =
`windowTitle`), виджетное — через `SheetFrame`; холст листа — `color.bg.surface` с
первого пикселя, без полосы оконного хрома над шапкой. Стек листов не ограничен в
глубине (событие → карточка → изображение — штатно), каждый накрытый лист затемняется
на одну долю сильнее (`SHEET_SCRIM_ALPHA_PER_SHEET` / `SHEET_SCRIM_ALPHA_MAX`,
арифметику ведёт `presentation/wiring.py`). Листы НИКОГДА не запоминают размещение:
фиксированный размер по умолчанию, рост вместе с главным окном до предела содержимого,
дальше — прокрутка. Ни одно диалоговое окно приложения не входит во вложенный цикл
событий: `.exec()` в `app/presentation/` запрещён AST-гейтом
`tests/test_no_dialog_exec.py` (белый список — только системные попапы `QMenu`).

### 1.1 Два нелистовых экрана

| Экран | Как открыть | Как закрыть | Помнит размещение |
|---|---|---|---|
| Лаунчер игр (первый запуск) | запуск `python -m app.main` — модальный `exec()` до появления главного окна; единственный оставшийся блокирующий показ, экран загрузки вне цикла qasync | «Открыть»/двойной клик по строке игры → главное окно; Esc/закрытие нативной рамкой = выход из приложения | нет (экран загрузки; в `UiPrefs.windows` роли нет) |
| `MainWindow` | выбор игры в лаунчере; либо пересборка при смене игры (тот же процесс) | закрытие окна = завершение приложения (`pkill -if "app.main"` для QA-прогонов) | да — роль `main` (`presentation/geometry_memory.py`); без сохранённой рамки открывается 1280×800 (NRI-0018 Д5); сохранённая рамка возвращается как сохранена, клампится в подключённый экран |

| Лист (`windowTitle` шапки) | Как открыть | Как закрыть | Размер / прокрутка |
|---|---|---|---|

| Карточка сущности (4 типа) | двойной клик/Enter по строке панели деталей; «Изменить»-путь из предпросмотра отсутствует (предпросмотр read-only); двойной клик по результату-сущности в поиске; ссылка-упоминание в тексте события открывает карточку | «Сохранить», «Отмена», «Закрыть», Esc | то же |
| «Типы событий…» | «+» → «Типы событий…» на шкале | «Закрыть» = Esc | фикс. по умолчанию |
| «Импорт из .xlsx…» | меню импорта (`docs/functional-checklist.md` §9) | «Закрыть» = Esc; «Отмена» не тронута | фикс. + прогресс импорта |
| «Обзор мира…» | меню «Обзор мира…» | «Закрыть» = Esc | по умолчанию 520×760, содержимое скроллится |
| «Документация» / «Changelog» | меню «О приложении» | «Закрыть» = Esc | 720×620, прокрутка сохранена |
| «Настройка LLM…» | меню LLM → «Настройка LLM…» | «Сохранить» (лок закрытия на время записи), «Отмена», «Закрыть», Esc | 640×560, футер «N из M» |
| «Настройка календаря» (мастер) | «Настройки → Календарь…» в любой игре; первый запуск новой игры — после показа главного окна тем же путём (`call_soon`, без вложенного цикла) | «Применить» / «Отмена» / «Закрыть» / Esc (закрыто без применения = «Стандартный») | ширина = ширине родительского окна, тело скроллится |
| «Просмотр изображения» | клик по картинке в карточке/предпросмотре (название доступности «Открыть изображение») | «Закрыть» = Esc | 720×600 |
| «Выберите <тип>» (пикер привязки) | привязка существующей сущности из карточки события/сущности | выбор строки / «Отмена» / Esc | фикс. по умолчанию |
| «Сменить игру…» | Файл → «Сменить игру…» (контент лаунчера внутри листа) | «Закрыть» = остаётся та же игра; подтверждение: unsaved-гард → снятие всего стека листов → `shutdown()` старого окна → новый `MainWindow` под ролью `main` в том же процессе | как у лаунчера |
| «Стол» (пульт стола) | плашка-полоса «Стол · N игроков» над строкой поиска (пока работает сервис стола) | «Закрыть» = Esc; закрытие НЕ останавливает стол и ничего не спрашивает — останов только кнопкой «Остановить стол» | фикс. по умолчанию |
| Редактор/заполнение/пресет чар-листа — НЕ лист | см. 1.3 (окно-исключение) | — | — |

### 1.3 Фиксированные исключения

| Исключение | Как открыть | Как закрыть | Помнит размещение |
|---|---|---|---|
| Окно списка чар-листов | меню «Чар-листы» | крестик окна | да — роль `sheet_list` |
| Окно редактора чар-листа (Design) | из списка чар-листов | крестик + `force_close` при смене игры/выходе | да — роль `sheet_editor` |
| Окно заполнения чар-листа (Fill) | «заполнить»/посадка из списка или пульта стола | крестик + `force_close` | да — роль `sheet_fill` |
| Окно выбора пресета | кнопка пресета в списке/редакторе чар-листов | выбор / Esc | **проверить вживую** (AGENTS.md относит пресет к окнам-исключениям с памятью размещения, но `UiPrefs.windows`/`SheetWindowsManager` ведут роли только `main`/`sheet_list`/`sheet_editor`/`sheet_fill`) |
| Полоса «Стол · N игроков» + «Остановить стол» | поднимается сервисом стола (`presentation/views/table_host/cluster.py`) — единственно законная поза: безродный `Qt.Tool \| FramelessWindowHint \| WindowStaysOnTopHint`, `WA_ShowWithoutActivating`; парит над затемнением листа, следует за перемещением/ресайзом/сворачиванием главного окна | «Остановить стол» (останавливает сервис сразу) | не applicable (следует за главным окном) |
| Малые системные диалоги Qt (выбор файла, ввод имени, подтверждения, сообщения) | из соответствующих действий; `QFileDialog` всегда с `DontUseNativeDialog`; тексты русские через `QTranslator` + `qtbase_ru.qm` | штатно | нет |
| Попапы: сетка дат, список часов, попап упоминаний, меню комбобоксов и контекстные меню, тултипы | по месту использования (например чип «Сейчас» → попап даты/часов; `@` + 2 символа в `MentionField`) | клик/Enter/Esc | нет (попапы) |
| Окно «Лист» игрока (из пульта стола) | клик по строке игрока в пульте стола; живое окно поднимается, вторая копия не создаётся | крестик | read-only, пока стол запущен; размещение — **проверить вживую** |

### 1.4 Меню-гейт при стеке листов

`ApplicationWiring.sheet_stack_changed(bool)` деактивирует пункты, открывающие листы,
пока стек поднят; пункты чар-листов и системные пути остаются активны. Прежний
`MenuWindowRegistry` упразднён; дедупликация окон чар-листов осталась собственным
механизмом `SheetWindowsManager`.

## 2. Флоу

Состав меню и кнопок ниже взят из кода (`app/presentation/views/main_window.py`,
`app/presentation/views/timeline_island.py`), поведение — из
`docs/functional-checklist.md` и `AGENTS.md`. Кейсы указаны файлом и префиксом ID из
`docs/qa/test-cases/README.md`.

### F01. Запуск приложения и лаунчер игр

- **Старт:** `python -m app.main` (или `python dev_run.py`).
- **Действия:** осмотреть лаунчер (приглашение, список игр, кнопки «Новая игра»,
  «Импорт», «Удалить», «Открыть», переключатель «Светлая тема»); создать игру новым
  именем; открыть игру двойным кликом/«Открыть»; удалить игру; «Импорт» `.nri`
  (метаданные отображаются; импорт в существующую игру — предупреждение о дубле).
- **Промежуточные экраны:** системные диалоги ввода имени / выбора файла
  (`DontUseNativeDialog`); подтверждение удаления.
- **Финал:** главное окно выбранной игры; при закрытии лаунчера без выбора — выход.
- **Возврат:** только через Файл → «Сменить игру…» (F02).
- **Первый запуск новой игры:** мастер календаря открывается листом ПОСЛЕ показа
  главного окна тем же путём, что и вход из меню (F12).
- **Кейсы:** `01-launcher-archive-import.md` (TC-LNCH, TC-GARC, TC-XLSX-импорт из
  архива), `10-*.md` (TC-THME — тема с лаунчера), `09-images.md` (TC-IMGS — каталог
  новой игры).
- **Спеки:** `openspec/specs/game-launcher/spec.md`, `game-archive/spec.md`,
  `interface-language/spec.md`, `ui-theme/spec.md`.

### F02. Смена игры

- **Старт:** главное окно → Файл → «Сменить игру…».
- **Действия:** открывается лист «Сменить игру…» (контент лаунчера, шапка
  «Сменить игру…» + «Закрыть»); выбор игры; при несохранённых изменениях — unsaved-гард.
- **Промежуточные экраны:** подтверждение unsaved-гарда; системные диалоги имени/файла.
- **Финал:** снятие всего стека листов → `shutdown()` старого окна →
  `Application._build_main_window(game)` → новый `MainWindow` под ролью `main` в том же
  процессе (без перезапуска).
- **Возврат:** «Закрыть»/Esc без выбора = остаётся та же игра.
- **Кейсы:** `01-launcher-archive-import.md` (TC-LNCH), `04-main-window-sheets.md`
  (TC-SHET — класс окна, TC-MAIN).
- **Спеки:** `openspec/specs/game-launcher/spec.md`, `modal-sheets/spec.md`.

### F03. Экспорт игры `.nri`

- **Старт:** Файл → «Экспорт игры…».
- **Действия:** системный диалог сохранения (путь задаёт пользователь); запись ZIP
  `game.db` + `meta.json`.
- **Промежуточные экраны:** системный файловый диалог.
- **Финал:** файл `.nri` на диске; сообщение о результате.
- **Возврат:** в главное окно; пункт остаётся активен даже при поднятом стеке листов
  (системный путь, не лист).
- **Кейсы:** `01-launcher-archive-import.md` (TC-GARC).
- **Спеки:** `openspec/specs/game-archive/spec.md`.

### F04. Главное окно: шкала → панель деталей → колонка предпросмотра

- **Старт:** после выбора игры; без сохранённой рамки окно открывается 1280×800,
  жёсткий системный минимум 1024×680 (`main_window.py`).
- **Состав:** `QSplitter` ровно из трёх панелей — шкала времени слева, панель деталей
  в середине, островок предпросмотра сущности справа (дефолтные размеры `[330, 390,
  500]`, общий минимум `PANE_MIN_WIDTH`, ни одна панель не схлопывается).
- **Действия:** выбрать событие на шкале (одиночный клик) → панель деталей показывает
  карточки событий/сущностей; выбрать строку сущности в средней колонке → живая область
  предпросмотра справа; двойной клик/Enter по строке шкалы → лист «событие»;
  одиночный клик по строке шкалы → только выбор; клик-промах мимо строк сбрасывает выбор;
  фильтр окна «С / По» + сброс «✕» (фильтр сохраняется per-game); чипы «Сейчас» и сосед
  список часов (час — только отображение, в производные величины не входит).
- **Пины (NRI-0025):** до 4 карт — не больше 3 закреплённых + живая внизу; высоты делятся
  равными долями, каждая скроллится независимо, шапка закреплённой карты остаётся сверху;
  кнопки пина — ровно четыре формулировки: «Закрепить карточку» / «Открепить карточку» /
  «Уже закреплена» (неактивна) / «Можно закрепить только 3 карточки» (неактивна); пины живут в
  `game_settings` под ключом `preview_pins`.
- **Промежуточные экраны:** попапы «Выбор даты» и списка часов (нативные окна-попапы).
- **Финал:** состояние колонок и пинов сохраняется в игре; размещение окна — роль `main`.
- **Возврат:** никуда не уходит — это корневой экран; прокрутка неизменной закреплённой
  карты сохраняется между кадрами (`slotScrollMemory`, фикс 2026-10-03).
- **Кейсы:** `04-main-window-sheets.md` (TC-MAIN, TC-GRID), `05-entity-preview-pins.md`
  (TC-PREV, TC-PINS), `03-events-timeline.md` (TC-TLNE), `02-calendar.md` (TC-NOWD).
- **Спеки:** `openspec/specs/main-window/spec.md`, `entity-preview/spec.md`,
  `preview-pins/spec.md`, `event-timeline/spec.md`, `current-date/spec.md`,
  `ui-layout-grid/spec.md`.

### F05. Создание и редактирование события, подсобытия

- **Старт:** «+» на шкале → «Новое событие»; двойной клик/Enter по строке шкалы;
  правый клик по строке ГЛАВНОГО события → «Создать подсобытие»; двойной клик по
  результату-событию в поиске.
- **Меню «+» (ровно):** «Новое событие», «Новый персонаж», «Новая локация»,
  «Новая организация», «Новый предмет», разделитель, «Типы событий…»
  (`ADD_MENU_ITEMS` + `event_types_action`); Esc/промах — ничего не эмитит.
- **Действия в листе события:** обязательные поля (без них «Сохранить» заблокирован),
  даты, «Бессрочно» → `∞`, «Родительское событие» (`ThemeComboBox`: «—» +
  главные события без редактируемого; «—» поднимает в главные), «Час начала» /
  «Минута начала» (минуты активны только при выбранном часе; границы из
  `current_calendar()`, ничего не зашито 24/60), связи (привязать существующих через
  пикер «Выберите <тип>», создать новую связанную, отвязать лишние), предыстория и
  характеристики (с `@`-упоминаниями).
- **Промежуточные экраны:** лист пикера «Выберите <тип>»; попапы дат; лист создаваемой
  связанной сущности (стек листов); отмена родительского диалога не оставляет сущность в БД.
- **Финал:** «Сохранить» → одна транзакция UoW, событие на шкале; время печатается
  хвостом `, HH:MM` через `date_utils.format_event_start` (без времени — подпись
  бит-в-бит прежняя).
- **Двухуровневость:** ровно два уровня; родитель обязан существовать, быть безродным и
  не быть самим собой — отказ по-русски доходит до пользователя; «Создать подсобытие»
  открывает диалог с предзаполненными родителем и датой родителя, время пустое.
- **Возврат:** закрытие листа = фокус в главное окно, стек снимается.
- **Кейсы:** `03-events-timeline.md` (TC-TLNE, TC-SUBE, TC-EVTM),
  `06-entities-search-mentions.md` (TC-EADD, TC-RELC, TC-MENT),
  `04-main-window-sheets.md` (TC-SHET).
- **Спеки:** `openspec/specs/event-timeline/spec.md`, `event-subevents/spec.md`,
  `event-time/spec.md`, `entity-addition/spec.md`, `related-entity-creation/spec.md`,
  `mentions/spec.md`, `modal-sheets/spec.md`.

### F06. Типы событий

- **Старт:** «+» → «Типы событий…».
- **Действия:** редактирование набора типов (лист с шапкой «Типы событий» + «Закрыть»).
- **Финал:** изменения применяются write-through; «Отмена» не тронута нормой.
- **Возврат:** «Закрыть» = Esc.
- **Кейсы:** `03-events-timeline.md` (TC-EVTP).
- **Спеки:** `openspec/specs/event-types/spec.md`, `modal-sheets/spec.md`.
- **Замечание:** точный состав полей редактора типов — **проверить вживую**.

### F07. Карточка сущности (персонаж / локация / организация / предмет)

- **Старт:** «+» → «Новый <тип>»; двойной клик/Enter по строке сущности в панели
  деталей; двойной клик по результату-сущности в поиске; клик по ссылке-упоминанию;
  строка «Переходит к сущности» из снимка мира или предпросмотра.
- **Действия:** поля по типу (`personality` — только персонаж; image — персонаж/
  организация/локация; tasks — 3 типа; music_url — все типы); рейтинг 1–20 с цветовым
  фоном; изображение: загрузка/превью/удаление; музыка: ссылка и режим редактирования
  (кнопка «✎» названа «Изменить ссылку на музыку»); M2M-вкладки: привязать / создать
  связанную / отвязать.

### F21. Просмотр изображения

- **Старт:** клик по картинке в карточке сущности, в панели деталей или в предпросмотре

- **Финал/возврат:** «Закрыть» = Esc → предыдущий лист.
- **Кейсы:** `09-images.md` (TC-IMGS, TC-IMGD), `04-main-window-sheets.md` (TC-SHET).

### F22. Переиспользуемые состояния, общие для всех экранов

> ⚠️ **Пределы харнесса для всех живых флоу этого реестра** (`аудит 2026-10-01 «modal-sheets» (отчёт архивирован)`
> §Пределы харнесса): синтетический фоновый координатный клик долетает не до всех целей
> (виджетные SheetFrame-листы и контролы QML-островов молчат при живом AXPress) — молчание

> спроецированы со смещением — в поля заходить только press-действием и
> `type_text(element_id=…)` с подтверждением фокуса скриншотом.

`AGENTS.md` § «Accessibility tree contract»): ① строки попапа упоминаний — только
клавиатура после фокуса поля; ② набранный текст `MentionField` и инлайн-редактора листа —
