## Общие предусловия и конвенции

- Запуск: `python -m app.main` (или `python dev_run.py`); завершение — `pkill -if "app.main"`.
- Изоляция: одноразовая игра `qa-2026-10-03`; существующие игры не открывать и не удалять.
- Кнопки генерации ИИ не нажимать (реальный endpoint); состояния генерации проверять только тестами с имитацией.
- Пути файла токенов и файла предпочтения темы спецификацией не заданы — см. «Пробелы» П1–П2; кейсы, правящие эти файлы, используют найденный вручную файл и фиксируют вопрос.
- «Пиксель снят» — скриншот/zoom живого окна или headless-рендер теста, как требует конкретная спека.
- Ссылки «ПNN» — вопросы раздела «Пробелы» в конце файла.

## Пробелы

Вопросы, на которые спецификации данных им specs не дают ответа; кейсы выше не выдумывают ожидаемое сверх записанного:

- П1. Путь/имя файла предпочтения темы спецификацией не задан (нужен для кейсов «первый запуск», «битое предпочтение», «битые байты», хранения выбора).
- П2. Путь/имя файла semantic-токенов спецификацией не задан (нужен для кейсов битых токенов и смены значений токенов).
- П3. Текст и уровень записи в логе при битом предпочтении и битых токенах не заданы (спека требует только «ошибка SHALL попасть в лог»).
- П4. Критерий «различимы» для chart-палитры на фоне `color.bg.surface` не quantified (контраст/порог не заданы).
- П5. Противоречие qml-shell: сценарий «Save без valid-гейта» (пустое имя — карточка эмитит запрос сохранения) против требования «Обязательные поля листов единообразны» (пустое название — «Сохранить» выключена). Ожидаемый исход Save при пустом названии карточки не определён.
- П6. Противоречие ui-widget-catalog («поля диалогов события и карточки SHALL остаться на widgets-редакторе», попавер «пока widgets-редактор не удалён») против qml-shell (целиком QML-острова, widgets-вёрстка удалена без feature flag). Актуальная норма не определена.
- П7. Текст «поясняющего текста» в просмотре изображения при отсутствии pixmap оригинала и preview не задан.
- П8. Текст «одного нативного предупреждения» при нечитаемом/битом файле изображения не задан.
- П9. Число видимых строк попапа комбобокса («высота ограничиваться несколькими строками») не задано.
- П10. Величина «фиксированного отступа» между текстом заголовка и кнопкой действия слота заголовка не задана.
- П11. Допустимое поведение ввода рейтинга вне диапазона 1–20 (clamp, откат или запрет ввода) не задано.
- П12. Способ смоделировать «запись в базу не удалась» / «сохранение ещё выполняется» для ручных прогонов не задан.
- П13. Способ получения сборки и «машины без dev-окружения» для проверок бандла и сравнения dev/сборки спецификациями не задан.
- П14. Наблюдаемый (визуальный) способ проверки архитектурных инвариантов (один QQmlEngine, 1:1 публичные API, состав context properties, отсутствие tooltipBridge) не задан — кейсы фиксируют наблюдаемую половину, инвариант остаётся за тестами.
- П15. Конкретный экран с неподключённым к теме корнем для проверки отсутствия наследования скина (сценарии «Карточка сущности не скинается…», «Немигрированный диалог не затронут») не указан; при тотальной подключённости сценарии проверяемы только на канвасе.
