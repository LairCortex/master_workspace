## game-calendar-core (TC-CALC)

### TC-CALC-001 — Круговой обход всех видов дней

- Требование: Координата и ключ даты игрового мира
- Сценарий: Круговой обход всех видов дней
- Тип: состояние
- Приоритет: P1
- Статус: уточни
- Предусловия: применён кастомный календарь с разными длинами месяцев и вставным днём (мастер).
- Шаги: 1) в попапе даты пройти первый и последний день каждого месяца, плашку вставного дня, год 1 и год 9999 обеих эр 2) на выбранные дни поставить события 3) перезакрыть карточку/попап на каждом событии.
- Ожидаемый результат: каждая дата возвращается ровно той же координатой (месяц/день, вставной день, год, эра); порядок событий на шкале совпадает с хронологией обхода.
- Источник: openspec/specs/game-calendar-core/spec.md#Координата и ключ даты игрового мира

### TC-CALC-002 — Один слот — одна дата

## Пробелы

Поведение нужно для проверки, но спецификацией не задано; кейсы со статусом «пробел» ожидаемое не выдумывают.

1. Ручных средств проверки числовых инвариантов ядра (побитовое равенство ключа функции `era_key`, размещение ключей в 64-битном знаковом целом, инъективность текстов кодека) спеки не задают — кейсы закрепляют только наблюдаемые следствия (CALC-003, CALC-018, CALC-029, CALS-016).
2. Как UI показывает полный список причин валидации («обе причины, а не первую встретившуюся») — не задано; мастер специфицирует русскую формулировку на ступень (CALC-011, CALC-026).
3. Путь передачи ядру/приложению координаты, которой нет в активном календаре (для проверки различимого отказа без тихой нормализации), через UI не задан (CALC-014, ERAS-005).
4. Средств проверки сохранения поведения смежных помощников `cmp_era_dates` / `assert_range` спеки не задают (CALC-021).
5. Наблюдение ответа кодека «машиночитаемые причины отказа, без исключения» для неразбираемого текста не специфицировано (CALC-030).
6. Средства воспроизвести ошибку применения «на середине обхода» (для проверки атомарного отката) не заданы (CALS-020, CALW-025).
7. Глазная проверка отсутствия правила `QCalendarWidget` в генерируемом тематическом листе не специфицирована (проверяется только перекраской) (CALG-010).
