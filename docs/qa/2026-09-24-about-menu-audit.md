## Форма документов (пункт 1)

- `DocViewerDialog` — `QDialog` 720×560 (min 640×480, `doc_viewer_dialog.py:47-48`), показ через
  `dlg.open()` (`main_window.py:239,245`) = WindowModal. Живьём на macOS: НЕ отдельное перемещаемое окно,
  а карточка-лист — `AXSheet` дочерний узел главного окна (`windows=1`, `sheets=1`, геометрия
  (154,104) 720×560, центрирована на родителе; роль отдаётся и в дереве доступности как `Sheet`).
  Это НЕ QML-лист внутри вайр-лайта EventDialog и не sheet из-под титлбара — свободно плавающая модалка-карта.
- Заголовок НЕ отрисован: `setWindowTitle("Документация"/"Changelog")` не виден нигде — карточка начинается
  сразу первой строкой markdown; AXTitle/AXDescription самого `AXSheet` — `missing value` (пусто).
  Различить два документа можно только по первой строке текста и не по оболочке.
- Не-модалность НЕ подтверждена нативным путём: при открытом документе все пункты «О приложении»
  (включая чекбокс логов), «Файл» и «Настройки» — `AXEnabled=false`; при этом почему-то `LLM` остаётся
  enabled. Фоновый AXPress «Добавить событие» под документом сработал (EventDialog открылся стеком
  поверх документа) — это канал доступности в обход Qt-модальности; для пользователя меню-гейт означает
  «главное окно заблокировано». Задачи пункта «проверить не-модалность» НЕ выполнена — поведение обратное.
- Повторное «О приложении → Документация»: каждый вызов создаёт новый экземпляр
  (`main_window.py:235-245` — `dlg = _DocViewerDialog(...)` без учёта открытого) — живьём зафиксированы
  ДВА одинаковых листа README одновременно (в дереве — два `Sheet`, значение каждого `TextField`
  = те же 13 542 символа); raise/переиспользования нет. «Документация» + «Changelog» — тоже два независимых
  окна-листа одновременно (разминтизации нет).

## Рендер контента (пункт 2)

- Контент грузится полностью в один `ThemeTextArea` (`mono: true`, `text: docViewerVm.text`) — AX-значение
  поля = весь файл (README: 13 542 символа), но видимая область ×28–29 строк (межстрочный шаг ≈18 pt,
  высота окна 560 pt): README 177 строк → доступна ~1/6; CHANGELOG 1358 строк (292 КБ) → ~2%.
- **Скролла нет вообще**: `DocViewerRoot.qml` — `ThemeTextArea` в `Rectangle`/`ColumnLayout` без
  `ScrollView`/`Flickable`/`ScrollBar`. Подтверждено живьём четырьмя способами: `scroll(element_id)` —
  0 пикселей смещения; реально отправленные 30–40 «стрелка вниз» и PageDown (frontmost) — экран статичен;
  AX-`focused` на поле + стрелки — без сдвига; Cmd+A не даёт выделения (фокус/каре́т в остров не приходят).
  Текст ниже видимой области в UI недостижим.
- Ширина: мягкой ширины набора нет — текст занимает всю ширину карточки (~688 pt из 720); при этом

  резки/обрезка кода нет (zoom подтвердил: строки упираются ровно во внутренний край, символы целые).
  Длина строки ~88 глифов при Menlo 13.
- Кегль 13 px (токен `font.size.md`), моноширинный Menlo (`font.family.mono`), markdown НЕ рендерится:
  заголовки сырыми `#/##/###` тем же кеглем и цветом, что body — визуально неотличимы; инлайн-код —
  только обратные котики. Скролла Changelog до конца добиться невозможно; верхняя запись — свежайшая,
  `## [0.17.2] — 2026-09-16` (совпадает с верхушкой `docs/CHANGELOG.md`).

- **AB1 (скролл, критично).** Документ в DocViewer не прокручивается ничем: нет ScrollView/ScrollBar,

  README и ~2 % CHANGELOG. Repro: «О приложении → Документация» → прокрутить (любой способ).
  `app/presentation/qml/DocViewerRoot.qml` (нет Flickable/ScrollView), use-site `main_window.py:235-245`.
  Пинится оффскрин: структура документа с ScrollView/прокруткой + `QAbstractScrollArea`-ожидание? — сейчас
  нет ни одного теста скролла острова.
- **AB2 (шапка/закрытие, важно).** У карточки нет ни заголовка, ни видимой кнопки закрытия: windowTitle
  не отрисован (macOS-карта без титлбара, `AXTitle` пуст), «Документация» и «Changelog» визуально — два
  одинаковых серых прямоугольника; закрыть можно только Esc, никак не подсказано.
  `main_window.py:236-245` + `DocViewerRoot.qml`.
- **AB3 (модальность, важно).** Документ блокирует меню (все пункты About/Файл/Настройки disabled) —
  второй документ/настройки/тумблер логов закрыты, пока не закроешь первый; ожидаемая не-модальность
  не выдержана, гейт при этом несогласован (LLM остаётся enabled). `dlg.open()`, `main_window.py:239,245`.
- **AB4 (дубль, минор).** Повторный пункт открывает такую же карточку поверх (зафиксировано два листа
  README одновременно) — raise/reuse отсутствует; при frontmost это скрыто AB3, при неактивном приложении —
  проходит. `main_window.py:235-245`.
- **AB5 (путь лога, минор).** Лог пишется в корень репо / рядом с exe вместо `~/.nri_manager`, которое
