  «Карточка». Остатка панели снимка мира в колонках нет: правая колонка —
  предпросмотр, пустое состояние — ровно штатная подсказка «Выберите сущность в
  среднем столбце — здесь появится её карточка».

## Чекпоинт 2 — пункт меню «Обзор мира…» и его окно

**ВЕРДИКТ: БЛОКЕР. Пункт «Обзор мира…» невидим в нативной строке меню macOS —
окно недостижимо из UI; живые проверки самого окна невозможны.**

Воспроизведение (детерминированное):

1. Запуск приложения, главное окно активно (frontmost). В строке меню видны только
   Apple, Python, «Файл», «Чар-листы», «Настройки», «LLM», «О приложении»
   (zoom области 0–900 pt, x2; затем скриншот всего дисплея — дальше правее пусто).
2. `System Events` → перечисление модели меню (`name of every menu bar item of
   menu bar 1` + пункты каждого подменю): «Обзор мира…» нет ни элементом строки, ни
   в подменю («Файл» → «Сменить игру…», «Экспорт игры…»; «Настройки» → «Светлая
   тема», «Календарь…», «Импорт из .xlsx…»; «LLM» → «Настройка LLM…»;
   «О приложении» → «Документация», «Changelog», «Сохранять логи в файл»,
   «Версия 0.18.0»). То есть Qt не «пересадил» действие в существующее меню —
   элемент отсутствует в NSMenu-модели полностью.
3. Причина (подтверждена изолированным зондом, код репозитория не менялся):
   минимальное PySide6-приложение из этого же `.venv` с `QMenuBar`, одним
   `addMenu("ZZMenu")` и «голым» `QAction("ZZBareEntry")`, добавленным прямо в
   `addAction` менюбара (ровен паттерн `main_window.py:119–123`) — в нативной
   строке показал только «ZZMenu», `ZZBareEntry` отсутствует. Ограничение
   cocoa-менюбара Qt: элемент без подменю на верхнем уровне не отображается.
4. Других эмиттеров `MainWindow.world_snapshot_requested` в коде нет (grep по
   `app/`): сигнал рождает только это QAction → живьём открыть окно нельзя никак.

Следствие: подпункты чекпоинта (немодальность, заголовок «Обзор мира», 520×760 по
центру при первом открытии, повторный вызов поднимает живое окно, закрытие
освобождает ключ, запоминание рамки) на реальном экране НЕ проверены — окно
неоткуда открыть. Все они оффскрин-пиннуты:
`tests/presentation/test_world_snapshot_window.py` (NonModal + заголовок + 520×760;
дедуп реестра и релиз слота; центрирование без сохранённой рамки; рамка
запоминается/восстанавливается; clamp за экрана) и
`tests/ui/test_e2e_world_snapshot_window.py` (действие меню открывает одно живое
немодальное окно; round-trip рамки; активация сущности открывает карточку).
Зелёный оффскрин этот класс дефекта не видит принципиально: там нет нативного
менюбара, тест триггерит QAction напрямую.

Рекомендация (follow-up FU-1, blocker): сделать пункт достижимым на macOS —
поместить действие в подменю (естественное место — «Файл» → «Обзор мира…»,
либо собственное меню-обёртка верхнего уровня). Формулировка спеки/AGENTS.md
«`QMenuBar`-действие, висящее прямо на строке» невыполнима как «голый» пункт на
macOS — нужна правка контракта окна в ту же сторону, затем живой ре-аудит
всего чекпоинта 2.
