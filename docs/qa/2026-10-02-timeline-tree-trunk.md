## Вердикт

**Дефект ПОДТВЕРЖДЁН.** Серый вертикальный отрезок ствола рисуется внутри карточки
развёрнутого родителя, перечёркивает её насквозь и пересекает нижнюю границу карточки,
продолжаясь вниз до локтя первого ребёнка. В эталоне 2026-09-30 внутри карточки
родителя какой-либо линии нет вообще.

## 1. Что видно глазами (_live_)

Замеры по `docs/qa/assets/2026-10-02-tree-trunk/01-live-tree-today-parent-3children.png`
(2 px/pt, начало отсчёта экрана (0,200)):

| Что | Значение |
|---|---|
| Колонка ствола (улица дочернего отступа) | экран `x ≈ 35 pt` (PNG x=70) |
| Левая граница карточки родителя | экран `x ≈ 15 pt` → линия стоит **внутри** карточки, ~20 pt от левого края |
| Начало сегмента | экран `y ≈ 217` — уровень строки подписи родителя (ровно `rowParentSegment.y: row.captionLineY`) |
| Нижняя граница карточки («сегодня») | экран `y ≈ 258` (PNG y=116) — **ствол пересекает её** |
| Конец непрерывного прогона | экран `y ≈ 378` — локоть последнего ребёнка |
| Цвет ствола | RGB(154,151,143) = `#9A978F` — это ровно токен `color.fg.muted` (dark), серый |
| Цвет рамки карточки «сегодня» | RGB(161,118,56) — оранжевый акцентный |

Пиксельный замер колонки x=35 даёт **один непрерывный серый прогон y=217…378**: от
подписи родителя вниз, сквозь строку описания «тест», сквозь нижнюю оранжевую границу
карточки, по улице детей, через локти «Ребёнок 1» и «Ребёнок 2» до локтя «Ребёнок 3».

Стыковка с локтем первого ребёнка: горизонтальное плечо локтя лежит на уровне строки
подписи ребёнка и идёт от той же улицы (x≈35) к цветной метке ребёнка — то есть
родительский сегмент визуально является началом этого же ствола, «вползающим» в карточку.

Про цвет на ВЫДЕЛЕННОЙ карточке (пункт задания): состояние «клик = оранжевая заливка»
в этом прогоне получить не удалось — весь синтетический ввод доходит до строк лестницы
либо как accessibility-Press (а он по контракту острова равняется двойному клику и
открывает карточку события), либо не доходит вовсе; реальные клики через System Events
также схлопнулись в двойной клик (открылся «Редактировать событие»). Поэтому зафиксировано
состояние «сегодня» (рамка без заливки) — геометрия та же. По коду delegate
(`app/presentation/qml/TimelineRowDelegate.qml:343-351`) на выделенной строке цвет
сегмента переключается на `color.accent.fg` = `#141418` (тёмно-графитовый), т.е. поверх
оранжевой заливки карточку перечёркивает тёмная полоса; серый `#9A978F` — в обычном
состоянии и на рамке «сегодня» (измерено живьём). По эталону внутри карточки
не должно быть никакой линии ни в одном состоянии.

## 2. Отличия от эталона

Эталон: `docs/qa/assets/2026-09-30-lucide-pass-main-window/2026-09-30-dark-timeline-tree-expanded-chevron-down.png`
(копия — `04-reference-etalon.png`, сравнение бок о бок — `03-comparison-live-vs-etalon.png`).

| | Эталон 2026-09-30 | Live 2026-10-02 |
|---|---|---|
| Внутри карточки родителя (рамка «сегодня») | линий нет, чистый холст | серый ствол от строки подписи до нижнего края |
| Где начинается ствол | строго НИЖЕ нижнего края карточки, на улице дочернего отступа, и сразу уходит в локоть первого ребёнка | на 40+ pt раньше — из середины карточки родителя |
| Пересечение границы карточки | нет (рамка замкнута целиком) | есть (ствол режет нижнюю границу «сегодня»-рамки) |
| Отступ детей, локти, улица | как сейчас | то же — соответствует |

Формулировка отличия одним предложением: эталон рисует ствол только «на улице детей»
(ниже карточки), а текущий рендер дополнительно рисует `rowParentSegment` — продолжение
ствола вверх, внутри карточки родителя, из-за чего карточка выглядит проткнутой.

## Рекомендация (без правок в этом прогоне)

Чтобы совпасть с эталоном, ствол должен начинаться от стыка под родителем: убрать
отрисовку `rowParentSegment` внутри родительской строки (или обрезать её ровно по
нижний край карточки, не входя в неё). Цветовая ветка `selectedRow → accent.fg` тогда
станет не нужна для этого элемента.

## Ограничение прогона (честно)

Инструмент computer-use не смог породить одиночный «мышинный» клик выделения по строке
QML-острова: accessibility-Press строк по контракту равняется двойному клику (открывает
карточку), фоновые координатные клики до MouseArea строк не доходили, а реальные клики
System Events схлопнулись в двойной. Состояние «родитель выделен (залит акцентом)»
не зафиксировано пикселями; зафиксировано идентичное по геометрии состояние «сегодня».

`trunkX = 0` с родительским сегментом, за которое пользователь 2026-10-02 и потребовал
перенос улицы на дочерний отступ («the 1 px tree line rode the parent card's left outline
border and cut it»). Живой билд строго чище этой картинки: улица на инденте (20 pt
от рамки), рамка целиком оранжевая. Расхождение «улица не на краю строки, как в PNG» —
задокументированный фикс (AGENTS.md, пользовательская правка 2026-10-02), а не регресс.
