   чистого фона между правой границей квадратика (388–389) и первой точкой

2. **Строго меньше соседних зазоров кнопка↔кнопка: PASS.** 4,5 pt против

   чекбокс с подписью визуально читается одним элементом — подтверждено и

3. **Текст не обрезан, кнопки не съехали: PASS.** Все пять контролов строки

## Побочная находка: AX-пресс чекбокса не переключает тему — FAIL шага 4

**Критерий «пресс по element id переключает тему» не выполнен.**

- Живой прогон: `click(element_id=e14)` («via AXPress») #1 → `value=1`,
  галка с accent-заливкой отрисована (zoom-доказательство), НО палитра
  осталась тёмной, `ui.json` не перезаписан, stderr приложения пуст — слот
  `_on_theme_toggle` не вызывался (`set_theme` пишет файл сразу). Пресс #2 →
  `value=0`. Тема за прогон не сменилась ни разу; состояние возвращено в
  исходное (dark, без галки).
- Координатные клики инструмента в это приложение вообще не
  доставлялись (клик по квадратику и по строке списка — без реакции и без
  выделения), поэтому путь «мышь→ clicked» живьём не проверен; это предел
  инструмента, не дефект приложения.
- Оффскрин-механизм (тот же `GameLauncherDialog`, offscreen Qt, изолированный
  prefs в temp): `QAccessible…actionInterface().doAction("Press")` → полная
  цепочка (clicked → `themeToggleRequested` → тема light → ui.json записан,
  галка следует биндингу); `doAction("Toggle")` → только `checked=1`, сигнал
  не emitted, тема dark, файл не тронут — **в точности живое поведение**.
  Биндинг `checked: currentTheme === "light"` после Toggle выживает и
  самокорректируется при следующем реальном переключении темы.
- Вывод: живая cocoa-проекция нажатия для роли CheckBox выполняет действие
  **Toggle (setChecked)**, а не Press (`onClicked` не происходит) — элемент
  остаётся addressable, галка честнеет после первого реального change темы,
  но AT-пользователь/автоматизация получают «включено» без переключения
  темы. Запись AGENTS от 2026-09-23 («press toggled the theme and wrote
  ui.json») относилась к контролу до фиксированной чекбокс-семантики
  NRI-0016 D2; правка `spacing` к этому отношения не имеет — находка
  самостоятельная и кандидат в реестр пределов дерева
  («AX-пресс stock CheckBox доходит как Toggle, onClicked не живёт») с
  оффскрин-пином `doAction("Toggle")`.
