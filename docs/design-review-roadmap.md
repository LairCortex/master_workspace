## Стандарт готовности куска (для всех четырёх)

1. Каждый правимый пункт сначала пинится оффскрин-тестом там, где поведение выразимо без дисплея (по списку пина в задаче); непинящееся перечислено в design куска явно.
2. `QT_QPA_PLATFORM=offscreen python -m pytest` зелёный, гейт покрытия 100 % не задет.
3. Финальный таск куска — живой ре-аудит computer-use затронутых сценариев (throwaway-игра, AI-кнопки не нажимать), результат — дописка «починено/живёт дальше» в соответствующий QA-отчёт; новый предел дерева доступности — только с записью в AGENTS.md в том же изменении.
4. Артефакты (AGENTS/CHANGELOG/functional-checklist) — в том же изменении; эта карта обновляет статусы после вливания; закрытие карты — статусом последнего пакета.

| ID | Что | Причина |
|---|---|---|
| S1 | «Python» в имени меню на dev-запуске | артефакт упаковки: у `.app` из PyInstaller имя из бандла; правки кода нет |

| A6/quirk | «not visible» при прессе QML RadioButton главного окна | канал тула (проверено в обоих режимах), не дефект |

| D7 | Светлая тема не синхронизирует NSAppearance нативной шапки | наблюдение; требует исследования Qt-внутренностей — откладывается отдельным решением |
| M6 | Дерево доступности главного окна: части островов «детьми» кнопки «Найти» | следствие island-встраивания; починка = перестройка моста дерева, эффект только для тулов |

## Замечания по переносимости пина

- нативный гейт меню macOS под листом (`AXEnabled`) пинится только живьём; оффскрин — свойство `windowModality` и наличие кнопки выхода (норма П1);
- обрезки вкладок (M1) и поля даты (M2 — правка в П4) — оффскрин geometry-пин + живьём читабельность (`zoom`);
- физическая мышь (W2 на живой мыши, S2) в CI невыполнима; контракт — `QAccessible doAction("Press")` (паттерн NRI-0012/AGENTS).
