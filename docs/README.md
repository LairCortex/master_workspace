# НРИ Сценарий Менеджер

Десктоп-приложение для создания и управления сценариями настольных ролевых игр (НРИ).

## Требования

- Python 3.11+
- macOS / Linux / Windows

## Установка (для разработки)

```bash
# Клонировать репозиторий
cd master_workspace

# Создать виртуальное окружение
python3.12 -m venv .venv
source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate   # Windows

# Установить зависимости
pip install -e ".[dev]"
```

## Запуск приложения

```bash
source .venv/bin/activate
python -m app.main
```

При первом запуске откроется **диалог выбора игры** — создайте новую игру или выберите существующую. Каждая игра хранится в отдельном файле `games/<имя>.db`.

## Сборка (исполняемый файл)

Для создания standalone-приложения без необходимости установки Python.

> **Важно:** PyInstaller не поддерживает кросс-компиляцию — сборку нужно запускать на каждой целевой ОС. Папка `games/` создаётся рядом с исполняемым файлом при первом запуске.

### Быстрая сборка (Python уже установлен)

```bash
pip install -e ".[build]"
python build_app.py --clean
```

### Сборка на Windows с нуля

Если на компьютере ещё не установлен Python:

1. **Скачайте Python 3.11+** с [python.org/downloads](https://www.python.org/downloads/)
2. Запустите установщик. **Обязательно** поставьте галочку **"Add Python to PATH"** на первом экране
3. Нажмите **"Install Now"**
4. Откройте **PowerShell** (Win+X → Terminal) или **cmd** (Win+R → `cmd`)
5. Проверьте установку:

```powershell
python --version
# Должно вывести: Python 3.11.x или выше
```

6. Перейдите в папку проекта и соберите:

```powershell
cd C:\путь\к\master_workspace

# Создать виртуальное окружение
python -m venv .venv

# Активировать виртуальное окружение
.venv\Scripts\activate

# Установить проект и зависимости для сборки
pip install -e ".[build]"

# Собрать приложение
python build_app.py --clean
```

7. Результат: `dist\nri_manager\nri_manager.exe`
8. Папку `dist\nri_manager\` можно скопировать на любой Windows-компьютер и запустить `nri_manager.exe` — Python не требуется

### Сборка на macOS с нуля

1. Установите Python через Homebrew:

```bash
# Установить Homebrew (если ещё нет)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установить Python
brew install python@3.12
```

2. Соберите:

```bash
cd ~/путь/к/master_workspace

source .venv/bin/activate
pip install -e ".[build]"
python build_app.py --clean
```

3. Результат: `dist/НРИ Сценарий Менеджер.app`

1. Установите Python и системные зависимости:

```bash
sudo apt update
sudo apt install python3.12 python3.12-venv python3-pip \
    libgl1-mesa-glx libegl1-mesa libxkbcommon0 libdbus-1-3
```

2. Соберите:

```bash
cd ~/путь/к/master_workspace
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[build]"
python build_app.py --clean
```

3. Результат: `dist/nri_manager/nri_manager`

### Результаты сборки

| Платформа | Результат | Путь |
|---|---|---|
| **macOS** | `.app` bundle | `dist/НРИ Сценарий Менеджер.app` |

### Автоматическая сборка (CI/CD)

Проект настроен на автоматическую сборку через **GitHub Actions**:

- **Push в main** — запускает тесты и сборку на macOS, Windows, Linux. Артефакты доступны для скачивания 14 дней
- **Тег `v*`** (например `v0.7.0`) — тесты, сборка, автоматический **GitHub Release** с архивами для всех трёх ОС

Для создания релиза:

```bash
git tag v0.7.0
git push --tags
```

Скачать собранное приложение: вкладка **Releases** на странице репозитория GitHub.

## Использование

### Выбор игры (лаунчер)

При запуске приложения открывается диалог выбора игры:

- **Новая игра** — введите название, создастся новый файл БД
- **Открыть** — откройте выбранную из списка игру
- **Удалить** — удалите игру (с подтверждением)
- **Импорт** — загрузить игру из `.nri`-архива (с подтверждением метаданных)

Переключение между играми без перезапуска: **Файл → Сменить игру**.

### Главное окно

Приложение состоит из трех зон:

1. **Поиск** (сверху) — глобальный live-поиск по всем сущностям (события, организации, персонажи, предметы, локации). Начните вводить от 2 символов — результаты появятся автоматически с задержкой 300мс. Поиск работает по имени, характеристикам и предыстории. Клик по результату открывает карточку сущности или выделяет событие на таймлайне.

2. **Таймлайн** (слева) — хронологический список событий, отсортированный по дате начала. Даты отображаются в формате `dd.MM.YYYY`. События визуально разделены, выбранное событие подсвечивается. Двойной клик по событию открывает диалог редактирования. Клик по событию загружает его содержимое в центральную панель.

3. **Детали события** (центр) — четыре вкладки с составляющими выбранного события:
   - Организации
   - Персонажи
   - Предметы
   - Локации

   Каждая сущность в списке показывает сводку: рейтинг, характеристики, предысторию, личность, задачи и количество связей. Если у сущности есть изображение — показывается thumbnail 100×100. Фон элемента окрашен в зависимости от рейтинга (серый → красный).

   Двойной клик по любой сущности открывает её карточку для просмотра и редактирования.

### Экспорт и импорт игр

#### Экспорт
1. Откройте игру
2. **Файл → Экспорт игры…**
3. Выберите путь для сохранения `.nri`-файла

Архив `.nri` содержит полную копию базы данных и метаданные (имя игры, версия, дата экспорта). ZIP-компрессия уменьшает размер файла.

#### Импорт
1. На экране выбора игры нажмите **«Импорт»**
2. Выберите `.nri`-файл
3. Подтвердите импорт (отображаются имя игры, версия, дата экспорта)

Если игра с таким именем уже существует — будет показано предупреждение.

### Обзор мира (World Snapshot)

Третья панель главного окна — визуальное представление мира на выбранную дату:

1. Выберите дату и нажмите **«Показать»**
2. Отображаются все события, в чей диапазон дат (дата начала — дата конца) попадает выбранная дата
3. Дерево отображает иерархию: Локации → Организации → Персонажи → Предметы
4. Персонажи без локации группируются в раздел «Без локации»
5. Фон узлов окрашен по рейтингу (серый → красный)
6. При наведении — тултип с описанием и рейтингом
7. Двойной клик — открывает карточку сущности
8. Внизу — статистика: количество событий, персонажей, организаций, локаций, предметов

### Меню

| Меню | Пункт | Действие |
|---|---|---|
| **Файл** | Сменить игру | Открывает лаунчер для переключения на другую игру |
| **Файл** | Экспорт игры… | Сохраняет текущую игру как `.nri`-архив |
| **О приложении** | Документация | Показывает README приложения |
| **О приложении** | Changelog | Показывает историю изменений |

### Создание события

1. Нажмите кнопку **"+"** в верхней части таймлайна
2. Заполните обязательные поля (отмечены `*`):
   - **Название** — имя события
   - **Дата начала** — когда событие начинается
   - **Дата конца** — когда событие заканчивается
   - **Характеристики** и/или **Предыстория** — описание события
3. Опционально: добавьте связанные сущности через вкладки внизу диалога
4. Нажмите **"Сохранить"** — кнопка активна только когда все обязательные поля заполнены

### Редактирование события

1. Дважды кликните на событие в таймлайне
2. Откроется диалог с предзаполненными полями и вкладками связанных сущностей
3. Можно изменить название, даты, описание, а также добавить/удалить связанные организации, персонажей, предметы и локации
4. Нажмите **"Сохранить"** — таймлайн и детали обновятся автоматически

### Редактирование сущности

1. Выберите событие на таймлайне
2. Дважды кликните на сущность в правой панели (на любой вкладке)
3. Откроется карточка с полями, специфичными для типа сущности:
   - **Персонаж**: имя, рейтинг, даты, описание, личность, задачи, изображение
   - **Организация**: имя, рейтинг, даты, описание, задачи
   - **Локация**: имя, рейтинг, даты, описание, задачи, изображение (карта)
   - **Предмет**: имя, рейтинг, даты, описание
4. Измените нужные поля и нажмите **"Сохранить"**

### Система рейтинга

Все сущности имеют рейтинг от 1 до 20:

- **1** — наименее важная (серый фон)
- **20** — наиболее важная (красный фон)
- Рейтинг задаётся при создании/редактировании карточки через `QSpinBox`
- В списке сущностей фон элемента окрашивается в соответствии с рейтингом

### Изображения

Для персонажей и локаций доступна загрузка изображений:

- В карточке сущности слева отображается превью (до 280×280)
- **"Выбрать файл"** — выбрать изображение с диска (PNG, JPG, BMP, GIF, WebP)
- Изображение автоматически ресайзится до 1000×1000 и сохраняется в БД как base64
- **"Убрать"** — удалить изображение
- В списке сущностей изображение показывается как thumbnail 100×100

### Управление связями между сущностями

Все M2M связи из схемы БД доступны для управления в карточках:

| Карточка | Связанные сущности |
|---|---|
| **Организация** | Персонажи, Предметы, Локации |
| **Персонаж** | Предметы, Локации, Организации |
| **Предмет** | Локации, Персонажи, Организации |
| **Локация** | Персонажи, Организации, Предметы |

Доступные действия:
- **"Привязать существующего"** — выбрать из списка всех сущностей в БД (мультивыбор)
- **"Создать нового"** — откроется карточка для создания новой сущности, после сохранения она автоматически привяжется
- **"Отвязать"** — удалить связь (сама сущность не удаляется)

### Обязательные поля

Для всех сущностей обязательны:
- **Описание** (характеристики и/или предыстория)
- **Дата начала**
- **Дата конца**

Даты поддерживают диапазон от 100 до 9999 года — подходит для фэнтези-сеттингов.

## Стек технологий

| Компонент | Технология |
|---|---|
| UI | PySide6 (Qt 6) |
| ORM | SQLAlchemy 2.0 (async) |
| БД | SQLite (aiosqlite) — отдельный файл на игру |
| Async | asyncio + qasync |
| Сборка | PyInstaller |
| CI/CD | GitHub Actions (macOS, Windows, Linux) |
| Бэкап | ZIP-архив `.nri` (game.db + meta.json) |
| Тесты | pytest, pytest-qt, pytest-mock, pytest-asyncio |
| Архитектура | MVVM |
