# Функциональный чек-лист

Регрессионная сеть на уровне пользовательских функций (компенсирует отсутствие E2E-тестов).
После **каждого** коммита реализации прогоняются затронутые группы; после финала change — полный прогон всех групп.

Статус:

| Статус | Значение |
|---|---|
| ✅ | Группа проверена, всё работает как раньше |
| ❌ | обнаружен регресс |
| ⏳ | не проверялась |

**Baseline (до рефакторинга, v0.13.0):** авто-прогон ✅ — 389/389 тестов, offscreen-запуск (launcher → Application.start → MainWindow → shutdown) без ошибок; ручной smoke 14 групп — закрыт без прогона (решение 2026-08-22): к моменту оформления чек-листа код уже рефакторен (§A–§D), baseline на старом коде невалиден; регрессионная страховка — характеризационные тесты волны 1 (tasks 2.1–2.5)

## 1. Лаунчер игр

- Создать игру (новое имя)
- Открыть игру
- Удалить игру
- Импорт из `.nri` (метаданные отображаются)
- Импорт `.nri` в существующую игру — предупреждение о дубле
- Файл → Сменить игру без перезапуска приложения

## 2. Глобальный поиск

- debounce 300 мс
- старт поиска от 2 символов
- регистронезависимость
- поиск по имени
- поиск по характеристикам
- поиск по предыстории
- клик по результату — открывается карточка сущности
- клик по результату-событию — выделение события на таймлайне
- результаты сгруппированы по типам

## 3. Таймлайн

- сортировка событий по дате
- выбор события — панель деталей
- двойной клик — редактирование события
- кнопка `+` — создание события
- контекстное меню — создание самостоятельных сущностей
- фильтр «С / По»
- сброс фильтра «✕»
- фильтр сохраняется после перезагрузки (per-game)

## 4. Событие (создание/редактирование)

- валидация обязательных полей (кнопка «Сохранить» блокируется)
- выбор дат
- «Бессрочно» → `∞`
- связи: привязать существующих сущностей
- связи: создать новую связанную сущность
- связи: отвязать лишние
- предыстория сохраняется
- характеристики сохраняются

## 5. Карточка сущности (4 типа)

- поля по типу: personality — только персонаж
- поля по типу: image — персонаж / организация / локация
- поля по типу: tasks — 3 типа
- поля по типу: music_url — все типы
- рейтинг 1–20 + цветовой фон
- изображение: загрузка
- изображение: превью
- изображение: удаление
- музыка: ссылка
- музыка: режим редактирования
- M2M-вкладки: привязать существующих
- M2M-вкладки: создать новую связанную
- M2M-вкладки: отвязать лишние

## 6. @Mention

- `@` + 2 символа → popup с иконками
- навигация стрелками + Enter
- выбор кликом
- ссылка кликабельная → открывает карточку сущности
- обратная совместимость старых текстов с маркерами

## 7. World Snapshot

- выбор даты → активные события (диапазон / `∞`)
- 5 секций без дубликатов
- «Показать всё»
- цвет по рейтингу
- тултипы
- двойной клик → карточка
- статистика внизу

## 8. Кастомные месяцы

- диалог настроек месяцев
- пустые поля = стандартные названия
- сброс к стандарту
- отображение в таймлайне
- отображение в деталях
- отображение в snapshot
- отображение в календаре
- отображение в поиске
- per-game хранение

## 9. XLSX-импорт

- импорт 5 типов сущностей
- заголовки колонок по имени
- строки без обязательных полей пропускаются с предупреждением
- даты `YYYY-MM-DD` (текст)
- даты native Excel
- прогресс импорта
- отчёт «Создано / Пропущено»

## 10. Экспорт/импорт `.nri`

- экспорт через меню
- структура ZIP: `game.db` + `meta.json`
- импорт через лаунчер

## 11. LLM-AI-ассистент

- визард 8 шагов
- «Проверить соединение» (1 токен)
- статусы `not_configured` / `ready`
- ✨ на текстовых полях
- очередь генераций
- блокировка поля при генерации
- ошибки: RU-тексты
- ошибки: ретраи 429/5xx
- глобальный конфиг 0600
- per-game промты

## 12. Изображения

- ресайз ≤ 1000×1000
- base64 в БД
- превью 280×280
- thumbnail 100×100

## 13. Бессрочность

- чекбокс скрывает поле даты
- `∞` на таймлайне
- snapshot активен на любую дату после начала
- фильтр включает бессрочные

## 14. Рейтинг

- spinbox 1–20
- цвет серый → красный в списках
- цвет серый → красный в snapshot
