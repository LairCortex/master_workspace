Два эпика подряд, не параллельно: сначала токены на текущем QtWidgets, потом перенос presentation в QML. QML не стартует, пока W4 не влит; W5 желательно до Q2.

Источник правды для цвета/типа/отступа — один набор semantic tokens. Из него: QSS (мастер) и CSS (HTML игрока D1). Не два независимых скина.

QML как «дизайн-система с нуля» отклонено как первый шаг. Канвас чар-листа (`QGraphicsView`) в эпике W не переписываем.

## Зафиксированные рамки

- **Ценность** — одна палитра на мастере и игроке; потом смена тулкита, не наоборот.
- **W раньше Q.** Полный уход в QML включая канвас — эпик Q, не W.
- **Две поверхности:** десктоп + HTML D1. Телефон/софт-AP берут тот же CSS, что fill.
- **Не аргумент за QML:** текущие timeline и snapshot — список и дерево; «плотный IDE-layout» закрывается токенами и W2.
- **Не в этой карте:** карта мира вместо дерева snapshot; Figma-live preview; сторонний UI-kit.
- **Чар-листы** (A1–P) не открываем заново, кроме Q3 (тот же контракт, другой рендер).
- **Нативный шелл** — каркас окна на эпики Q и R: `QMainWindow`, нативная `QMenuBar` с тумблером темы, `statusBar`, `QSplitter`; все contents внутри — islands. Это не молчаливый долг: системное меню (macOS), ресайз панелей, рамка/Esc диалогов — нативные; полное QML-окно — отдельный архитектурный эпик, не в карте.
- **Системные попапы** `QMessageBox`/`QInputDialog`/`QFileDialog` действуют на все приложение (правило Q1, распространено с лаунчера); тултипы QML-островов — нативный shim-мост, не QML-overlay.
- **Поповеры выше края острова — widgets-мост** (правило grill 2026-09-05): QML-Popup обрезается границами `QQuickWidget`, поэтому любой всплывающий за край острова поповер — widgets-мост с координацией Python-стороной. Сейчас три: chip «Выбора даты» шкалы (Q2.5a, диапазон, в R не трогаем), однодатовый календарь `ThemeDateField` (R4, `_CustomCalendar`), попавер завершения упоминаний (R5). QML-Popup не заводим, пока в карте нет решения о всплытии островов выше их краёв.
- **`table_host`** — не chrome для QML: он уже темится теми же токенами через CSS (путь D1), в QML не переносится.
- **`MentionTextEdit` вне Q2, Q2.5 и Q3:** вместе со своими диалогами был вынесен в заблокированный Qx (grill 2026-09-03); **разблокирован grill 2026-09-05 без смены формата** — R5–R7 двухслойным зеркальным редактором; в R7 widgets-файл удаляется целиком (grep-инвариант). Деградация «показывать сырые маркеры» в редакторе запрещена; сводка detail и `LIKE`-поиск сырой storage не чистят (grill 2026-09-05³). Гибрид «QML-остров с widgets-редактором» запрещён — оба стека поля одновременно или никто. Контролы потребителя (дата, related, AI, кликабельная картинка) едут в куске этого острова, не отдельным хвостом.
- **Tooltip-шим островов:** прикреплённое свойство в `nri.components` (объявление текста в QML), показывает Python-сторона острова одним системным `QToolTip` (уже темизован общим листом попапов); вводится Q2.5a; R4 — только snapshot (`tooltipBridge`), search/detail без моста; собственных QML-оверлеев-подсказок не заводим.
