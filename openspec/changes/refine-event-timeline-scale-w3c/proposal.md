# Proposal: refine-event-timeline-scale-w3c

## Why

W3b влил вертикальную шкалу дней, но его рейка (date rail) сознательно декоративна: клики и перетаскивания по ней глотаются. Навигация по длинному диапазону при этом — только колесо (ровно один ряд за нотч) и jump по событиям; попасть на конкретную дату или задать диапазон фильтра быстрым жестом на самой шкале нельзя. Grill-сессия 2026-08-31 зафиксировала W3c: интерактивная рейка — клик-прыжок, follow-дата под курсором, drag диапазона — без смены топологии рейки (in-list, рисование delegate остаётся).

## What Changes

- Зона рейки (`rail_width()`) перестаёт быть декоративной и становится интерактивной навигационной зоной: ЛКМ-нажатия и вертикальный drag обрабатываются рейкой, текстовая зона строк ведёт себя как раньше (клик/dblclick выбирает и открывает событие).
- Клик по дню на рейке = прыжок: день встаёт верхним рядом под липкую дату; `currentIndex` переезжает (якорь jump-команд живёт), выделение и id-сигналы не трогаются; пустые дни — валидные цели прыжка. Якорь нормализуется к первому ряду дня.
- Follow-дата: пока курсор в рейке (и всё время drag'а), липкая оверлей-дата показывает полный игровой день под курсором, с возвратом к дате верхнего ряда на уход курсора. Новый floating-виджет не заводится.
- Drag диапазона по рейке = фильтр по датам: подсветка диапазона accent-derived wash'ем на движении, `filter_changed(start, end)` ровно один раз на release; чип синхронизируется как от поповера. Drag снизу вверх нормализуется min–max; однодневный drag эквивалентен клику; drag поверх активного фильтра ставит новый фильтр по видимым дням; после захвата значим только y (clamp к видимому диапазону, release вне виджета применяет последнюю дату); auto-scroll при drag'е нет.
- Разведение жеста: drag-режим только ЛКМ и только после смещения на порог пикселей (~3–4), иначе — клик-прыжок; двойной клик в рейке глушится; колесо (один ряд/нотч), Alt+Up/Down и «+»-меню без изменений.
- Сброс фильтра — единственный путь: кнопка «Сбросить» в чип-поповере; рейка жестов сброса не получает.
- Чистая Qt-бесплатная геометрия рейки (y→день, clamp, нормализация диапазона) — в модуле строк вне Qt, по традиции `timeline_rows.py`; hit-test юнитами + grab/pixel-приёмка по традиции W1+.
- **BREAKING нет**: id-контракт (`event_selected`/`event_double_clicked`), контракт ViewModel/wiring, семантика `filter_changed`, чип-фильтр и его поповер — без изменений; меняются только обработка ввода в зоне рейки и поведение липкой даты.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `event-timeline`: рейка из декоративной становится интерактивной зоной (требования «Шкала времени» и «Привязка событий к рейке» теряют clauses о необрабатываемости кликов); добавляются клик-прыжок по дню и drag-диапазона (новое требование «Интерактив рейки»); липкая дата временно показывает день под курсором в рейке («Липкая дата»); чип-фильтр дополняется вторым способом задания диапазона с синхронизацией и сохранением единственного сброса в поповере («Чип-фильтр диапазона»).

## Impact

- `app/presentation/views/timeline_widget.py` — eventFilter рейки заменяется на обработчик нажатий/drag'а зоны рейки (`mousePress/Move/Release` или фильтра), hover-обработчик дополняется follow'ом sticky, делегат дорисовывает wash-полосу drag'а; sticky-оверлей получает временный follow-режим.
- `app/presentation/views/timeline_rows.py` — чистые хелперы геометрии дня (`day_at_y`, clamp/нормализация диапазона) без Qt.
- `app/presentation/viewmodels/timeline_viewmodel.py` / `Application._wire_*` — без изменений (drag использует существующий `filter_changed`-канал панели).
- Тесты: юниты новой геометрии, hit-test/жестовые тесты view (Qt), grab-тесты wash-полосы и follow-sticky, существующие инварианты (hex, live-retheme) без правок.
- Вне скоупа: toggle-сжатие пустых дней (кандидат дальше по roadmap), auto-scroll при drag'е, зум, drag-редактирование дат события, жесты сброса на рейке, клавиатурные аналоги интерактивов.
