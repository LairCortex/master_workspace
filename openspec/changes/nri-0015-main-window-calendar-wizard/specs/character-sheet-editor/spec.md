## ADDED Requirements

### Requirement: Пустые списки вкладок объясняют себя

Каждая вкладка списка чар-листов без элементов SHALL показывать текст-подсказку о ближайшем действии (как панель событий), а не пустой прямоугольник; подсказка SHALL исчезать при первом элементе.

#### Scenario: Вкладка «Шаблоны» пуста

- **WHEN** вкладка «Шаблоны» открыта в игре без шаблонов
- **THEN** виден текст подсказки про создание шаблона или пресет, панель не выглядит зависшей
