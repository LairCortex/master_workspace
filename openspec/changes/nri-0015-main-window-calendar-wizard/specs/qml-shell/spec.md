## ADDED Requirements

### Requirement: Обязательные поля листов единообразны

Во всех листах создания/правки (событие, карточка сущности) метки SHALL оформляться одинаково: подпись метки обязательного поля оканчивается «:» и содержит маркер обязательности «*»; сохранение SHALL блокироваться, пока любое обязателное поле листа пусто (пустое название события и пустое название карточки запрещают запись одинаково).

#### Scenario: Карточка не сохраняется без названия

- **WHEN** в карточке персонажа пусто поле «Название: *»
- **THEN** «Сохранить» выключена, как и в событии с пустым названием

#### Scenario: Метки не расходятся

- **WHEN** сравнить метки «Название: *», «Предыстория: *» события и карточки
- **THEN** двоеточие и маркер обязательности есть везде, ни одна обязалная метка не голая
