# Design: nri-0015-main-window-calendar-wizard

## Context

Аудиты 2026-09-24: критики W1/W2/W3 у мастера календаря (раскладка предпросмотра, мёртвая AX-смена выбора, вложенный `exec()` из `Application.start()` с тихим qasync-крахом), M1/M4/M5+B4 у главного окна (обрезки вкладок, безликая пустота, отсутствие памяти окон — механик `saveGeometry/restoreGeometry/QSettings` в проекте нет). Карточка и событие расходятся гейтом «Сохранить» и маркировкой. Формат окон (модаленость/шапки) — контракт П1 (`nri-0014`), здесь он предполагается влитым.

## Goals / Non-Goals

**Goals:** вкладки читаемы без ручного раздвигания; пустые панели объясняют себя; ни одно именованное окно не рождается недоступным и помнит место; мастер первого запуска не роняет цикл, выбор читается тулами, вёрстка плотная; контракты двух листов совпадают; попап даты не дезориентирует.

**Non-Goals:** перестройка вкладки/панелей (только метки, ширина, заглушки); ThemeDateField роль+ширина (П4); формат мастера (носитель — П1); «Стола», LLM, логи (П3).

## Decisions

### T1. Короткие подписи вкладок — поле реестра `tab_label`
Факт типа живёт в `domain/entity_registry.py` (принцип «одно знание»): добавляется `tab_label` («Орг.», «Персы», «Вещи», «Локации» — утверждено гриллом), остаётся `plural_label` полным. `DetailPanelRoot` берёт `tab_label` для `Text` вкладки и `plural_label` как `Accessible.name`+tooltip (`tooltip_shim` живьём — предел ④, имя доступности несёт полное). Минимальная ширина вкладки = `implicitWidth` короткого текста + padding (без ручных pt-констант).
*Вместо:* elide+tooltip только — оставлял бы нечитаемые вкладки (отклонено гриллом); сжатие стретч-факторов сплиттера — лечило бы симптом дефолтной ширины.

### T2. Заглушки пустот — общий стиль, не новый каркас
В пустой панели деталей и вкладках чар-листов — строка `HintText`-стиля про ближайшее действие («Выберите строку — тут появятся детали», «Шаблонов ещё нет — создайте или возьмите пресет»). Текст — константа на потребителя; отдельного библиотечного компонента не вводится (три потребителя с разными текстами, абстракция раньше времени).

### T3. Память геометрий — расширение `UiPrefs`
`UiPrefs.windows: dict[str, list[int]]` в `ui.json` (роль окна → x,y,w,h; файл уже chmod 0600, менеджер один). Механика `presentation/geometry_memory.py`: `restore(window, role)`, `attach(window, role)` (сохранение по дебаунсу на moved/resized + гарантированно при close). Восстановление: `move` внутрь пересечения экрана (clamp с `availableGeometry` подключённых экранов), размеры — clamp min/экранный максимум. Роли: `main`, `sheet_list`, `sheet_editor`, `sheet_fill`, `table_host`; редактор и Fill без сохранённой роли получают детерминированный оффэкран-безопасный центр (B4 закрывается).
*Вместо:* Qt-нативного `saveGeometry()/restoreGeometry()` (байтовый blob) — нечитаем в ui.json, не клампится к экранам без своей обвязки; QSettings — новый канал хранения вразрез с «единственный дом `~/.nri_manager`».

### T4. Мастер: вёрстка, радио, первый запуск
Вёрстка (W1/W4/W5): панель предпросмотра — `ColumnLayout` без промежуточных отступов (шапка дней ← `GameCalendarGrid` целиком, сетка уже рисует строку заголовков — разрыв был следствием двойной шапки/отступов мастера, проверяется геометрическим пином); числа предпросмотра — токен `color.fg.primary` вместо muted (контраст); кнопочная строка одна (QDialogButtonBox в одном RowLayout: роль-отвергание слева, пара Назад/Далее + Применить справа), центрирование левого шага — выравнивающий stretch.
Радио (W2): обработчики переносятся с `clicked` на `toggled` с защитой от рекурсии существующим `blockSignals`-контура `VM._render`; пин — `QAccessible` `actionInterface().doAction("Press")` → VM сменила `kind` (оффскрин, паттерн AGENTS; живьём радио не проверяется — S2 не мешает оффскрину).
Первый запуск (W3/FI-6): `Application.start()` перестаёт владеть мастером: `_maybe_show_calendar_wizard()` перестаёт awaited-`begin()+exec()`; по завершении старта показывается то же окно, что создаёт `_on_calendar_wizard` (MenuWindowRegistry-совместимый модаленый top-level из П1, ApplicationModal), вызов — через `call_soon` в loop (qasync-нативный путь). Apply-ошибки идут существующим путем меню (аудит: «Применить здесь чистый, FI-6 не воспроизводится») — пользователь видит экран отчёта/ошибку. Пин: e2e-оффскрин — «новая игра стартом: start завершился, окно показано, мастер открыт поверх, отмена возвращает в окно; ни одного RuntimeError в логе цикла»; пин старт-контура не требует дисплея.

### T5. Единообразие листов (E2, CR3/CR4, E3/CR1, E4/B5)
Метки: общий формат «<Имя>: *» через существующий источник подписей (`_FIELD_SPECS`/model'ы VM), в карточке «*» добавляется к обязательным (Название). Гейт: `EntityCardViewModel.can_save` (или его эквивалент) AND'ит непустоту обязательных полей — поведение копирует `EventDialogViewModel` (проверить и синхронизировать тексты причин). AI-кнопка: `fieldLabel` привязывается к полю-мишени каждого usage-site (карточка персонажа — «Персонаж»/целевое поле, не «Событие»); позиция — строка внутри блока поля (метка+поле+✨ в одном контейнере), а не отдельный ряд между блоками. `ThemeComboBox`: индикор — свойство contentItem/background библиотеки (один пиксельный grab-пин: индикатор ⊂ rect поля).

### T6. Попап даты (P1/P2/P3)
П1: при отсутствии границ страница первой сетки — координата текущей календарь-даты, доступная уже в ряду чипа; обе сетки (вторая — та же, если границ нет). П2: постоянные подписи «Начало окна»/«Конец окна» над сетками (вторая видима до выбора — сейчас появляется только после). П3: в режиме «Все дни» — без accented-заливки всех ячеек; заливаются только выбранная граница и подсветка наведения; «границы рябят» лечится токеном `color.bg.hover`. Пиновый оффскрин: модель страниц/заливок попапа (свойства delegate), визуальная ровность — живой zoom.

## Risks / Trade-offs

- Т4 старт-контур трогает самый хрупкий путь (`Application.start` с миграциями/календарём): перед правкой — фиксация текущего поведения e2e-пином (red→green), возврат к `exec()` не планируется без снятия W3.
- `toggled`-контур радио может поймать двойные переключения — guard проверяется в том же оффскрин-тесте (счётчик обработчиков).
- Память геометрий при севшем разрешении — clamp грубый (окно сжимается к максимуму экрана): приемлемо против «за экраном».
- Короткие подписи вкладок — новый реестровый инвентарь (четыре строки); guard-тест требует `tab_label` у каждого типа (пустым не появится).
