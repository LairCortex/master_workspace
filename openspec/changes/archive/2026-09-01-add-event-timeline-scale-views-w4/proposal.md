# Proposal: add-event-timeline-scale-views-w4

## Why

Вертикальная шкала W3b/W3c перечисляет сутки за сутками: на длинных кампаниях пустые дни раздувают список, все события неразличимы (у события нет типа), а «дорожки по сущностям» из карты эпика W до сих пор не имеют адреса. Карта фиксирует: этот кусок — W4, он блокирует старт Q1 (QML), и его детальный дизайн зафиксирован grill-сессией 2026-08-31.

## What Changes

- Лестница единиц просмотра **сутки ↔ месяц ↔ год** вместо «зума»: строка ступени = одна каленendarная единица с счётчиком событий; пустые единицы остаются позициями-заглушками (сжатие пустоты = сама лестница, отдельных строк-пропусков нет).
- Управление лестницей: **Ctrl/Cmd + колесо** (с якорем) + переключатель ступеней в шапке. Колесо без модификатора, жесты рейки W3c и Alt+↑/↓ — без изменений; прежнее запретительное правило «зума нет, модификаторы шаг не меняют» отменяется частично (BREAKING для спеки «Шкала времени»).
- Единый закон единицы ступени: тик, клик-прыжок, гранула drag-фильтра и липкая метка считаются по текущей единице. Drag месяцами/годами эмитит нормальные границы дат (первое/последнее число) через неизменный чип-путь; семантика попадания фильтра не меняется.
- Клик по строке месяца/года приближает ступень; внешний выбор (поиск/детали) и jump-кнопки сами спускают лестницу до суточной строки события — id-контракт W3 неизменен.
- Группировка по сущностям: переключатель «выкл · персонажи · локации · организации · предметы»; на крупных ступенях — секции по сущностям (событие дублируется в каждой группе, «Без привязки» последней, внутри секции только тронутые ею единицы); на сутках группировка лишь упорядочивает события внутри дня.
- Скобки многодневок unit-aware: событие красит полосу через все единицы ступени, которых касается (сутки — без изменений).
- **Типы событий — новые данные per-game**: таблица `event_types` + `event_type_id` у событий (миграция `init_db()`, сид НРИ-дефолтов: Сюжет, Побочное, Слух, Встреча, Ров будней, Находка); редактирование — диалог из «+»-меню панели; назначение — селектор в диалоге события; цвет — индекс из новых токенов `color.chart.1…8` (никакого colorpicker'а). Точка цвета типа — слева от суточной строки.
- Настройки вида (ступень, группировка) не сохраняются: всегда «сутки · выкл» при открытии.

## Capabilities

### New Capabilities

- `event-types`: пользовательские типы событий per-game — таблица, НРИ-дефолты, редактирование (диалог «Типы событий…»), назначение в диалоге события, цвет как индекс токено-палитры; удаление отвязывает события.

### Modified Capabilities

- `event-timeline`: требование «Шкала времени» переписывается под лестницу единиц (сутки/месяц/год, позиции-заглушки пустых единиц, отмена части запрета зума, Ctrl/Cmd+колесо, переключатель ступеней); «Интерактив рейки» получает единую гранулярность единицы ступени и нормализацию drag-диапазона к границам единиц; требования о скобках, липкой дате, выборе и строках дополняются поведением крупных ступеней, секционной группировкой и точкой типа; «Оформление шкалы из токенов» расширяется цветами `color.chart.*`.
- `ui-theme`: файл semantic-токенов получает обязательные `color.chart.1…8` (обе темы, namespace → CSS-переменная web-игрока; употребляются только шкалой и диалогом типов).

## Impact

- **Ядро без Qt**: `app/presentation/views/timeline_rows.py` — `build_rows(events, unit, group_by)` со строками `EVENT / EMPTY_DAY / UNIT / SECTION`; `index_at_y`, `normalize_range`, jump-хелперы сохраняют contract равновысоких строк; `bracket_lanes` из виджета переезжает в ядро unit-aware.
- **Виджет/VM**: `timeline_widget.py` (делегат, рейка, липкая, Ctrl+колесо, переключатели шапки, спуск лестницы при внешнем выборе), `timeline_viewmodel.py` (unit/group_by, нормализация диапазонов).
- **Данные**: `init_db()`-миграция (`event_types`, `events.event_type_id`, сид дефолтов), `EventModel`/repository/domain `Event` + `event_type`, `EventService` (`event_service.py`, CRUD типов), `event_dialog.py` (селектор типа), новый диалог `event_types_dialog.py`, «+»-меню панели событий.
- **Тема**: `tokens.json` +8 обязательных chart-токенов (в PyInstaller `datas` уже попадает целиком; round-trip/CSS-приёмка W1-механики).
- **Тесты**: юниты ядра (единицы, секции, lane-скобки, гранулы), grab/pixel приёмка (hex точки = токен, Ctrl+колесо, drag-гранулы, спуск из поиска, live-retheme восьми цветов), инвариант «ни hex, ни `palette()`» продолжает сканировать `timeline_widget.py`.
- **Вне рамок**: drag-редактирование дат — W5; сохранение вида, colorpicker, дорожки на суточной ступени — не заводятся.
