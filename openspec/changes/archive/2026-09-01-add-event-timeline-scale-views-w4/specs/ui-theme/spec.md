## MODIFIED Requirements

### Requirement: Файл semantic-токенов

Поставка приложения SHALL содержать один файл semantic-токенов. Каждый токен SHALL задавать значения для светлой и тёмной темы. Файл SHALL не храниться в базе игры. Цвет, отступ, радиус и кегль, нужные chrome W1, SHALL быть токенами. Роли, реально используемые каталогом виджетов и статусами (цвет успеха, крупный кегль заголовка), SHALL быть токенами того же файла. Токен SHALL заводиться тем же изменением, что и правило QSS/CSS, которое его читает: обязательный токен без читателя не вводится (его отсутствие гасит тему целиком, а пользы не несёт). Сгенерированные QSS и CSS SHALL не быть вторым исходником в репозитории. Файл SHALL содержать обязательную хроматическую палитру `color.chart.1…8` — восемь парных (light/dark) цветов для категорий пользовательских данных; их читатели — шкала событий и диалог типов событий (в chrome-QSS и в CSS chrome web-игрока правила, читающие chart, не заводятся); значения в обеих темах SHALL быть различимы на фоне `color.bg.surface`.

#### Scenario: Смена значения токена

- **WHEN** в файле токенов меняют hex роли фона chrome и пересобирают/перезапускают приложение
- **THEN** лаунчер, chrome главного окна и CSS chrome страницы стола отражают новое значение без отдельной правки трёх копий цвета

#### Scenario: Не база игры

- **WHEN** открывают другую игру
- **THEN** набор токенов тот же (тема не переезжает в `game.db`)

#### Scenario: Новый токен каталога

- **WHEN** в файле токенов меняют значение цвета успеха или кегля заголовка
- **THEN** статусная подпись и заголовок на пилотных экранах меняются из нового значения без правок экранов

#### Scenario: Нечитаемый токен не вводится

- **WHEN** в набор пытаются добавить роль, которую не читает ни одно сгенерированное правило QSS и ни одна переменная CSS-тела (на примере концов градиента рейтинга и моноширинного шрифта)
- **THEN** такая роль отсутствует в обязательном наборе этого куска и заводится вместе с экраном, который её начинает читать

#### Scenario: Chart-палитра обязательна и различима

- **WHEN** файл токенов проверяют на полноту и контраст
- **THEN** все восемь `color.chart.*` присутствуют с значениями light и dark, и каждое значение различимо на `color.bg.surface` своей темы

#### Scenario: Chart-токен не протёк в chrome

- **WHEN** сгенерированные QSS и CSS chrome сканируют на употребление `color.chart.*`
- **THEN** ни одно правило chrome их не читает — палитру едят только шкала событий и диалог типов
