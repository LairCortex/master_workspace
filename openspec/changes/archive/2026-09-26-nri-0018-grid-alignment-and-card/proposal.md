# Proposal: nri-0018-grid-alignment-and-card

## Why

Живой просмотр 2026-09-25 вскрыл системную неряшливость визуальной сетки: разнородные ширины окон (480/540/620/700/720/750/860/1100), отступы-исключения (4 px у строки поиска, 8 px у просмотрщика документов), мелкие глимф-кнопки трёх калибров (28/30/естественная), подписи чекбоксов «висящие ниже» индикатора (метрика строки шрифта вместо центра чернил), и локали не дошедшую до заголовка карточки («Карточка: organization»). Дополнительно сокращения подписей вкладок (NRI-0015) оказались хуже полных имён при широком старте, а перенос кнопки полной генерации в шапку делает карточку собранной. Это пятый пакет дорожной карты дизайн-ревью (П5), следующий за закрытыми П1–П4.

## What Changes

- **Сетка_ui**: все окна приложения получают естественную ширину из шкалы кратной 40 с правилом «не уже содержимого» (420→440 лаунчер-миноры, 480 лаунчер, 560 пресеты, 640 LLM/xlsx, 720 событие/изображение/документ, 760 нижняя граница карточки, 1040 мастер (пересчитан по Д7), 1120 заполнение, 1280 редактор); отступы содержимого листов — единым токеном (исключения 4/8 px подтянуты); мелкие действующие глимф-контролы — квадрат 32×32 общим библиотечным компонентом (✕, ✎, все ✨, «+» шкалы, ↑↓−+ редактора/типов, ◀▶ навигации).
- **Чекбоксы/радио**: подписи центрируются по оптическому центру чернил, индикатор и подпись на одной линии, полоса чекбокса согласована с соседями; индикаторы нативных `QCheckBox`/`QRadioButton` тематизированных экранов (навигация календарной сетки, радио мастера) перекрашиваются из токенов вместо белой нативной ячейки.
- **Вкладки и старт**: вкладки деталей — полными именами реестра («Персонажи»), поле короткой подписи `tab_label` удалено из реестра; дефолтный старт главного окна 1280×800; восстановленная сохранённая рамка расширяется до порога «все вкладки целиком» (позиция и высота сохраняются). Это же закрывает OBS-1 строки «Дата:» снимка мира.
- **Карточка сущности**: заголовок локализован через реестр («Карточка: Организация»); кнопка полной генерации перенесена из строки «Название» в строку заголовка листа — сразу после текста заголовка, вид тот же ✨, доступное имя сохранено. Для единообразия то же размещение получает диалог события (зафиксированное допущение: требование привязывает оба листа одной фразой размещения).
- **Мастер календаря**: содержимое шага («Стандартный/Кастомный») прижато к левому краю текста вместо поштучного центрирования (частичный пересмотр W4 — строка кнопок не меняется); левая колонка мастера получает ширину по своему содержимому (ступень 40), излишек — предпросмотру; минимум окна пересчитывается; навигационная строка и сеточные попапы — единая высоты контролов 32 с тематизированным чекбоксом эры.

Вне этого пакета: FI-5-остаток (живой ре-аудит doc viewer/xlsx/LLM/стола/типов событий/панели деталей реального мышиного контура) — отдельный прогон без правок кода.

## Capabilities

### New Capabilities
- `ui-layout-grid`: визуальная сетка окон — шкала ширин кратная 40 с нижней границей содержимого, единый токен отступов листов, единые высоты контролов в ряду, квадратный облик мелких действующих глимф-кнопок (32×32) по всему приложению.

### Modified Capabilities
- `qml-components`: библиотека получает квадратный компонент мелких действующих кнопок; `ThemeCheckBox` центрирует подпись по оптическому центру чернил; `ThemeSheetHeader` получает слот действия сразу после текста заголовка; кнопка AI остаётся однотипной и входит в квадратное правило.
- `qml-shell`: шапка карточки сущности — локализованный заголовок из реестра и кнопка полной генерации после текста заголовка.
- `entity-generation`: размещение кнопки «Сгенерировать сущность» — в строке заголовка листа после его текста (единообразно карточка и диалог события), поведение и гейты без изменений.
- `main-window`: вкладки деталей носят полные имена реестра без обрезки; дефолтный старт 1280×800; восстановленная рамка расширяется до ширины «все вкладки целиком».
- `calendar-wizard`: левая раскладка содержимого шага; тематизированные индикаторы радио; ширина левой колонки по содержимому, пересчитанный минимум окна.
- `game-calendar-grid`: строка навигации — единая высота контролов (32), тематизированный чекбокс эры.
- `ui-widget-catalog`: индикаторы нативных `QCheckBox`/`QRadioButton` тематизированных экранов оформляются из токенов общим листом, off-skin остаётся нативным.

## Impact

- QML-библиотека: `nri/components/ThemeCheckBox.qml`, `ThemeSheetHeader.qml`, `ThemeAiButton.qml`; новый `ThemeIconButton.qml` (+qmldir, пины пиксельной приёмки).
- Острова: `EntityCardRoot.qml`, `EventDialogRoot.qml`, `TimelineRoot.qml`, `LauncherRoot.qml`, `SearchBarRoot.qml`, `SheetEditorRoot.qml`, `SheetFillRoot.qml`, `EventTypesRoot.qml`; ширины/отступы листов по таблице шкалы.
- Widgets: `calendar_wizard.py` (раскладка шага, ширины колонок, минимум), `calendar_grid.py` (навигация 32, тематизированный чекбокс); `app/presentation/theme/compiler.py` + токены (правила `QCheckBox`/`QRadioButton` индикаторов).
- Реестр и вид: `domain/entity_registry.py` (удаление `tab_label`), `entity_card_dialog.py` и `event_dialog.py` (заголовок через `display_label`, размещение AI), `views/main_window.py` (дефолтный размер), `presentation/geometry_memory.py` (расширение восстановленной ширины).
- Тесты: оффскрин-пины геометрий/текстов/квадратов, обновлённые пины `tab_label`/W4, живой ре-аудит компьютером финальным таском; гейт покрытия 100 % затрагивается всеми новыми строками.
