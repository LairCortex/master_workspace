# Proposal: nri-0016-table-llm-logging

## Why

Третий пакет закрывает утечку, перепутанный ввод и «видимость состояния»: закрытие панели «Стола» крестиком при работающем сервере не останавливает HTTP — порт остаётся слушаться до конца процесса (TB1, критично); QR/URL/PIN рисуются до запуска и не следят за правкой порта (TB2); «Выгнать» активна без выделения и молчит по нажатию (TB4); Enter в поле порта внезапно запускает стол (TB5). В окне «Настройка LLM…» два Repeater'а в одном GridLayout ставят сначала ВСЕ подписи, потом ВСЕ поля — на пяти страницах подписи смотрят на чужие поля (LS1, критично: риск сохранения значения не в тот промпт), выхода из листа восемь только по Esc и нет счётчика шагов (LS2). Лог пишется в корень репозитория вопреки `paths.py` (AB5), DEBUG-уровень handler'а недостижим при root INFO и файл бесполезен (AB6), закрытый лаунчер остаётся слушателем темы и тихонько падает в `RuntimeException` (D1). Версия нигде в UI не видна (AB7), переключатель темы в меню и лаунчере означает двумя способами одно (D2), экспорт открывается не рядом с играми (A4).

## What Changes

- **Стол**: `closeEvent` панели при работающем столе — подтверждение «Остановить стол?» → остановка и закрытие (отмена — стол живёт) (TB1); адрес/QR/PIN — только после успешного запуска, актуальны порту, правка порта до старта снимает показанное; QR — основной адрес из показанного списка (TB2, TB7); «Выгнать» активна только при выбранном игроке (TB4); Enter в панели ничего не запускает (TB5); PIN — 6 цифр (сервис, maxlength и проверка веб-клиента — синхронно), текст PIN выделяется (TB6); чекбоксы посадки — реальные `QCheckBox` (ремонтируется доступность; AX-пин контракта в П4); «Порт:» и плейсхолдер пустого списка игроков (TB7).
- **LLM-окно**: парная раскладка «подпись ↔ поле» на всех страницах промптов; окно не-модальное (по контракту П1) с постоянной кнопкой «Закрыть» и индикатором «N из 8» на всех листах (навигация не пишет, закрытие без подтверждения); единый корень «промпт/промпты»; слот имени поля — «Ключ API» (LS1–LS4).
- **Логи**: файл `~/.nri_manager/nri_manager.log` (как обещает `paths.py`) с ротацией 2 МБ × 3; ложное обещание DEBUG снимается (уровень handler = root); закрытое окно не остаётся слушателем темы — `remove_listener` у `ThemeRuntime`, подписка снимается при закрытии (D1).
- **Версия**: единый `app.__version__`, неактивная строка «Версия X.Y.Z» в меню «О приложении» (единственный живой показ версии), тест равенства pyproject↔`__version__` (AB7).
- **Мелочи настроек**: переключатель светлой темы — единая семантика «чекбокс с фиксированной подписью и состоянием ✓» и в меню, и в лаунчере (D2); «Экспорт игры…» открывается в каталоге `games/` (A4).

## Capabilities

### New Capabilities
- `app-logging`: файл журнала приложения — расположение, ротация, включение/выключение, и правило жизненного цикла слушателей состояния приложения.
- `app-version`: видимая пользователю версия приложения и её единый источник в коде.

### Modified Capabilities
- `character-sheet-host`: формат сессии панели стола (показ адресов только по факту запуска), остановка при закрытии с подтверждением, PIN шесть цифр и его выделяемость, гейт выгона, невзрывной Enter, доступность посадки, подписи панели.
- `llm-configuration`: форма настройки — парная привязка подписей к полям, оконный не-модальный формат с постоянным закрытием и счётчиком страниц, терминология «промпт».
- `ui-theme`: единая семантика переключателя темы во всех точках.
- `game-archive`: диалог экспорта открывается у каталога игр.
