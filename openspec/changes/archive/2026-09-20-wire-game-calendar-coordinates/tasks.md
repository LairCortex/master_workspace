## 3. Стартовый обход и применение календаря

- [x] 3.1 `CalendarSettingsService`: старт-обход шести таблиц в порядке «ремонт coord-колонок → сдвиг невалидных (`build_shift_report` + запись через `assign_coord`) → `reconcile_era_keys`»; переносы и очистки — в лог; тесты: идемпотентность (второй обход ничего не меняет), «ручное рассогласование лечится стартом» (ручной кастом + невалидные даты → старт без падения, записи сдвинуты, ключи корректны), стандартная игра — no-op-обход (specs game-calendar-settings «Ключи записей…»).
