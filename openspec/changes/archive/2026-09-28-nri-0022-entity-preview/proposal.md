# Proposal: nri-0022-entity-preview

## Why

Сейчас единственный способ «просто посмотреть» на сущность — открыть редактируемую карточку двойным кликом: тяжёлый жест для просмотра, а лёгкий (одиночный клик) не делает ничего. При этом правая колонка занята «Обзором мира» — снимком на дату, который нужен эпизодически, но место держит постоянно. Нужен читаемый предпросмотр выбранной сущности на месте, а обзор мира переезжает в вызываемое окно.

## What Changes

- Правая колонка главного окна вместо «Обзора мира» показывает читаемый предпросмотр последней выбранной в среднем столбце сущности: полные поля карточки только для чтения, компактные связи и @упоминания с переходом по клику, картинка с полноэкранным просмотром.
- Одиночный клик по строке сущности в среднем столбце выбирает её (подсветка + предпросмотр); двойной клик остаётся путём к редактированию. С клавиатуры: Press выбирает, Enter открывает карточку.
- «Обзор мира» выезжает из правой колонки в отдельное не модальное окно, открываемое действием «Обзор мира…» прямо в строке меню; содержимое и поведение окна — прежние, включая клик по строке → карточка.
- Предпросмотр живёт по правилу «последняя выбранная в среднем столбце»: смена/снятие события на таймлайне его не трогает; очистка — только при удалении показанной сущности, перезапуске или смене игры.
- Поиск получает единый жестовый язык: левый клик по результату-сущности — полный путь (событие на таймлайне → вкладка типа → подсветка строки → предпросмотр), двойной клик — редактирование (карточка сущности, событие — редактор события); правая кнопка мыши не делает ничего (резерв под будущее контекстное меню).
- Переходы по связям и упоминаниям из предпросмотра выбирают сущность в предпросмотре; если сущность есть в текущем списке среднего столбца — переключаемая вкладка и подсветка строки; таймлайн не меняется.
- Предметы получают полноценную картинку: ссылка на `images` в таблице предметов, колонка картинки в редактируемой карточке Предмета, миниатюра в строках и место в предпросмотре.
- Печать правок карточки обновляет предпросмотр; удалённая сущность предпросмотр очищает.

## Capabilities

### New Capabilities

- `entity-preview`: читаемый предпросмотр выбранной сущности в правой колонке — правило жизненного цикла выбора, состав полей, связи и упоминания с переходом, картинка, пустое состояние, очистка.

### Modified Capabilities

- `main-window`: панель деталей — одиночный клик выбирает строку (подсветка + предпросмотр), двойной клик открывает редактирование; память размещения окон получает роль окна обзора мира; правая колонка сплиттера — предпросмотр вместо врезанной панели снимка.
- `world-snapshot`: обзор мира живёт в отдельном не модальном окне из действия строки меню (память геометрии, повторный вызов поднимает живое окно); поведение содержимого, включая клик по строке → карточка, не меняется.
- `global-search`: левый клик по результату-сущности ведёт полный путь до предпросмотра; двойной клик открывает редактирование; правая кнопка неактивна.
- `image-storage`: сущность «Предмет» получает ссылку на `images` наравне с организациями, персонажами и локациями (колонка `image_id`, обнуление при удалении).
- `image-display`: слот картинки Предмета — просмотр preview в карточке/строке/предпросмотре и оригинала по клику, деградация при недоступном файле.
- `qml-accessibility`: контракт описаний активации строки панели деталей меняется на «Выбирает сущность» (Press) плюс Enter → карточка; связи/упоминания предпросмотра несут существующие описания переходов.

## Impact

- Presentation: `world_snapshot_widget.py` (хостинг окна, `MenuWindowRegistry`, роль геометрии), новый предпросмотр-виджет/QML-остров + вьюмодель, `detail_panel*` (одиночный выбор, Enter, связи/упоминания предпросмотра), `main_window.py` (строка меню, состав колонок сплиттера), `EntityCardRoot.qml`/`entity_card_dialog.py` (картинка Предмета), `SearchBar`/wiring (жесты поиска).
- Domain/DB: `entity_registry.py` (картинка у ITEM), `infrastructure/db/models.py` + миграция `image_id` для предметов через `init_db()`.
- Wiring/DI: цепочки выбор → предпросмотр, обновление после сохранения карточки, очистка при удалении/смене игры.
- Тесты: офскрин-пины жестов и доступности (покрытие 100% — шлюз), юнит-тесты миграции и репозитория предметов; документация: AGENTS.md (контракт окон), CHANGELOG, specs.
