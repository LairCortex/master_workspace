# Предложение: dd-reference-mechanics-text

## Why

Карточки справочных записей («Справочник…», поиск, упоминания, предпросмотр) сейчас печатают только имя, тип и подпись источника: блок «Текст» показывается лишь если запись несёт поле `desc`, а официальные файлы LSS его не имеют (0 из 107 и 0 из 66 записей) и схема не пропускает его на импорт. При этом сами датасеты уже несут человекочитаемое содержимое, которое нигде не печатается: трейты с названиями и полными описаниями («Чувство опасности», «Бешенство»), признаки вида/подвида, владения, навыки, слоганы подклассов, требования черт, поуровневые признаки классов. Справочник «не несёт информации» не потому, что её нет в датасетах, а потому что никто её не собирает.

## What Changes

- Карточка справочной записи шести типов начинает печатать блок «Механика»: читаемый русский текст, собранный из структурных полей записи (`grants`, `leveledGrants`, `prerequisite`, `size`, `subclassLevel`, `info`) без выдумывания прозы — печатается только то, что реально лежит в записи.
- Трейты (`trait`) печатаются полными: название признака отдельной строкой-заголовком, его `description` — абзацем под ним; это основной носитель текста в официальных SRD-файлах.
- Короткие гранты печатаются одна грант — одна строка с известными подписями: кость хитов, спасброски, владения доспехами/оружием, навыки (фиксированные и «выбор N из»), инструменты, языки, скорость, размеры, ASI, ресурсы, золото, снаряжение, вызовы «выбери одно», колдуновские гранты — по закрытому списку 28 типов схемы; неизвестный тип гранта печатается честной строкой «Признак без перевода: <тип>», запись не теряет карточку.
- `leveledGrants` печатается секциями «На уровне N:» в порядке уровней.
- Поле `desc` (если когда-нибудь пройдёт) остаётся первым блоком «Текст»; «Механика» идёт после него.
- Постулат честности unchanged: SRD-заклинания — только имя и строка «полный текст в LSS»; описания гримуаров — как были; никакого генерирования текста из головы.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `dnd-reference-records`: карточка справочной записи шести типов собирает читаемый блок «Механика» из структурных полей записи (трейты полными описаниями, прочие гранты — строками, поуровневые — секциями, неизвестный тип — честной строкой); карточка без механики выглядит как раньше.

## Impact

- `app/dd/domain/grant_render.py` (новый, Qt-free): чистый сборщик текста из записи датасета; словарь русских подписей ключей (доспехи/оружие/инструменты/навыки/характеристики/размеры/языки — частично переиспользует `character_render.STAT_LABELS/SKILL_LABELS`).
- `app/dd/presentation/reference_source.py`: `_record_blocks` перестаёт быть stub-вьюком `desc` и вызывает сборщик.
- Тесты: новый модульный тест рендерера на всех 28 типах грантов + ветках полей; тесты карточки источника; пин «постулат честности» для SRD-слагов не трогать.
- Спецификации: дельта `dnd-reference-records`. Документация: CHANGELOG, тест-кейсы 14.
