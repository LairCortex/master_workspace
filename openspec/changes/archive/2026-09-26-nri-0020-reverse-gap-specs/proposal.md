# Proposal: nri-0020-reverse-gap-specs

## Why

Ревизия 2026-09-26 сверяла 37 действующих спецификаций `openspec/specs/` с фактическим кодом приложения и нашла три области поведения, которые живут в коде, но не описаны ни одной функциональной требой:

1. **Глобальный поиск** (`SearchService`, `SearchViewModel`, остров `SearchBarRoot`) — упоминается в чужих спеках только как сосед (сценарий «внешний выбор» в `event-timeline`, E2E-поток в `ui-testing`, поставки острова в `qml-shell`), но собственные правила поиска — область, поля, триггер, группировка, пустое состояние — не зафиксированы нигде.
2. **Снимок мира** (`WorldSnapshotViewModel`, остров `WorldSnapshotRoot`) — `qml-shell` закрепляет только транспорт (имена сигналов фасада, формат строк, поставку списочной моделью); предметное поведение снимка (дата, секции, состав, сортировка, видимость статуса, статистика, перекраска при смене темы) не описано.
3. **Сериализация доступа к сессии** (`ApplicationWiring._spawn`/`run_locked`, `uow.lock`) — в `architecture-integrity` закреплена единая точка завершения транзакции, но не закреплён запрет двух одновременных обращений к одной сессии; нарушение этого порядка даёт не ошибку, а вечное зависание (регресс E2E-сьюта зафиксирован в комментариях `wiring.py`).

Это реверс-спецификации: код изменению НЕ подвергается, спеки описывают фактическое поведение и закрепляются существующими тестами.

## What Changes

- Новая возможность `global-search`: область и поля поиска, порог двух символов и debounce, группировка результатов по типам, пустое состояние, переход по клику, поиск имён как единый источник завершения упоминаний.
- Новая возможность `world-snapshot`: сборка по дате игрового мира, секции и раскрытие, состав снимка и пустые состояния, сортировка, носимость статуса в строке, открытие карточки, строка статистики, перекраска рейтингов при смене темы.
- Дополнение `architecture-integrity`: требование «каждое обращение из интерфейса к сессии — под единым замком» (замок принадлежит блоку работы; входы внешних диалогов проходят через переданный `run_locked`; вложенные `await` замок не берут).

Вне этого изменения: правки кода, исправление повреждённой строки в `ui-widget-catalog` (найдено при ревизии — отдельный гигиенический фикс), синк дельт в основные спеки (делается штатным шагом архивации изменения).

## Capabilities

### New Capabilities
- `global-search`: глобальный регистронезависимый поиск по всему миру игры (события и четыре типа сущностей) по названию, характеристикам и предыстории, с дебаунсом, группировкой результатов и переходом к цели; отдельный поиск только по именам обслуживает завершение упоминаний.
- `world-snapshot`: панель снимка мира главного окна — срез активных событий на выбранную дату (или всех событий), секции по типам с раскрытием, сортировкой и рейтинговой стилизацией, статистикой и переходом в карточку.

### Modified Capabilities
- `architecture-integrity`: добавляется требование сериализации всех обращений к сессии под единым замком блока работы (новые требые в дельте, существующие требования без изменений).
