# dnd-character-import Delta

## MODIFIED Requirements

### Requirement: Точки входа явные, сопоставления по имени нет

Импорт SHALL быть доступен из двух мест: создание нового персонажа из файла и «Перезаписать из файла LSS…» из карточки конкретного персонажа с подтверждением полной перезаписи; текст подтверждения фиксирован дословно: «Перезаписать персонажа из файла LSS? Поля, карточка D&D, текстовые блоки и сохранённый файл-снимок будут заменены содержимым файла.» Автоматическое сопоставление файла с персонажем (по имени или иному полю) SHALL NOT выполняться: экспорт LSS не содержит идентификатора, и выбор цели — всегда действие пользователя.

#### Scenario: Перезапись требует подтверждения

- **WHEN** выбрана перезапись персонажа из файла
- **THEN** показано подтверждение дословно «Перезаписать персонажа из файла LSS? Поля, карточка D&D, текстовые блоки и сохранённый файл-снимок будут заменены содержимым файла.»; без него персонаж и его файл-снимок не изменились
