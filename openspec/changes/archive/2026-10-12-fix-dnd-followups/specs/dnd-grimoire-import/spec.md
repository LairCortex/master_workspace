# dnd-grimoire-import Delta

## MODIFIED Requirements

### Requirement: Гримуарный файл проходит проверку с отчётом и ложится в глобальное хранилище

Импорт SHALL принимать файл заклинаний Foundry-формата: нечитаемый файл или структура вне формата SHALL отвергаться с причиной (ошибки), исправимые несоответствия — импортироваться с предупреждениями (тот же posture error/warning, что у датасетов). Файл SHALL храниться в глобальном хранилище приложения под своим идентификатором, переименование/замена хоумбрю-файла — с подтверждением; текст подтверждения замены фиксирован дословно: «Гримуар «<название>» уже в хранилище — заменить его можно только с вашим подтверждением.»

#### Scenario: Кривой файл не проходит

- **WHEN** выбран файл, не разбираемый как документ заклинаний Foundry
- **THEN** импорт откачан с русским сообщением о причине, в хранилище ничего не добавилось

#### Scenario: Замена подтверждается

- **WHEN** импорт файла с идентификатором уже сохранённого гримуара
- **THEN** запрашивается подтверждение дословно «Гримуар «<название>» уже в хранилище — заменить его можно только с вашим подтверждением»; без подтверждения старый файл цел
