# Предложение: dd-card-redesign

## Why

Волна `add-dnd-game-face` разложила поля всех карточек по табам «Обзор»/«Тексты»/«Связи», и эти таы видны всегда — и с модулем, и без него. Владелец зафиксировал норму: релиз 0.19.1 — неизменное ядро, всё модульное живёт над ним. Значит ядру возвращают прежний одноэкранный вид карточек, а табы (включая новые разделы D&D-персонажа и встречи) приносит только включённый модуль.

## What Changes

- **BREAKING (внешний вид ядра)** Карточки всех сущностей и событий возвращаются к одноэкранному виду 0.19.1: ядреных табов «Обзор»/«Тексты»/«Связи» нет; без модуля карточка неотличима от 0.19.1 (охрана профилем «модуль выключен»).
- Механизм табов в ядре остаётся «спящим»: полоса табов показывается только когда внешний источник принёс свои табы.
- Модуль, карточка события: два таба — «Основное» (целиком прежнее окно события) и «Встреча» (редактор без изменений). У всех событий D&D-игры.
- Модуль, карточка персонажа: четыре таба — «Основное», «Способности», «Личность», «Заклинания». Вкладка «D&D» прежнего образца исчезает: списки вида/подвида/класса/подкласса + уровень и файловые двери LSS переезжают на «Основное», выбор предыстории — на «Личность».
- «Основное» персонажа без модульных текстов: текстовые поля ядра «Характеристики» и «Предыстория» при включённом модуле скрыты (данные целы), на их месте — таблица характеристик D&D.
- Новая возможность `dnd-character-mechanics`: шесть характеристик с производным счётом (проверки, спасброски с владением от класса из датасета, навыки с переключателями владения, пассивные чувства), скорость, прыжки и переносимый вес по формулам, выбор черт из подключённых датасетов, блоки «Личности», ячейки заклинаний 1–9; всё ездит туда-обратно через импорт/«Экспорт для LSS» и читается ИИ-дозаполнению.
- Связи карточки с табами — пришитая полоса внизу окна на всех табах (своя прокрутка, до трети высоты окна); кнопки сохранения под ней.
- Предпросмотр правой колонки — зеркало карточки: у персонажа с модулем все секции модуля (текстом, без наложений), два ядреных текста скрыты; у события с модулем — секция «Встреча».
- Ядро расширяется обобщённым каналом «секции модуля» для предпросмотра; без модуля канал пуст.

## Capabilities

### New Capabilities

- `dnd-character-mechanics`: структурированные механики D&D-персонажа — таблица характеристик с производным счётом, владения, пассивные чувства, скорость, прыжки и вес, черты (ссылки на датасеты), блоки «Личности», ячейки заклинаний; хранение, формулы и круг данных через импорт/экспорт LSS.

### Modified Capabilities

- `entity-card-tabs`: ядро больше не раскладывает поля по ядреным табам — одноэкранный вид 0.19.1; табы появляются только от внешних источников; связи — пришитая полоса внизу окна на всех табах; размер окна по самому высокому содержимому.
- `dnd-character-extension`: табы «D&D»/«Заклинания» заменены четырьмя табами модуля; списки и уровень на «Основном», предыстория на «Личности», файловые двери на «Основном»; тексты ядра «Характеристики»/«Предыстория» скрыты при включённом модуле.
- `dnd-encounters`: таб «Встреча» — один из двух табов карточки события («Основное» = прежнее окно целиком); поведение редактора не меняется.
- `dnd-character-import`: конвертер документа LSS дополнительно заполняет механики (`dnd-character-mechanics`) — характеристики, владения, скорость, блоки «Личности», ячейки, черты.
- `dnd-character-export`: «Экспорт для LSS…» пересобирает документ из текущего состояния карточки вместе с механиками.
- `entity-preview`: предпросмотр — зеркало карточки: секции модуля персонажа и секция «Встреча» события при включённом модуле, скрытые ядреные тексты персонажа; через обобщённый канал секций модуля, пустой без модуля.

## Impact

- `app/presentation/qml/EntityCardRoot.qml`, `EventDialogRoot.qml` — возврат одноэкранной разметки со «спящим» механизмом табов; связи — пришитая полоса.
- `app/presentation/viewmodels/entity_card_island_view_model.py`, `event_dialog_island_view_model.py` — ядреные группы убраны, канал секций модуля.
- `app/dd/presentation/character_tab_frames.py` (новая вкладочная сетка), `dd_encounter_frame.py`, `character_tab_source.py`, новый лист «Основное»/«Личность»/«Способности».
- `app/dd/infrastructure/db/dd_models.py` + миграция модуля: колонки характеристик/владелений/скорости/личности/ячеек; новая таблица ссылок на черты.
- `app/dd/domain/character_render.py`, `app/dd/domain/character_editor.py`, `character_channel.py` — круг данных импорта/экспорта/дозаполнения.
- Предпросмотр: `EntityPreviewRoot.qml`, `entity_preview_view_model.py`, мост секций модуля в `presentation/wiring.py`.
- Спецификации и тесты перечисленных возможностей; профиль `NRI_DISABLE_DD_MODULE=1` — неотличимость ядра.
