## ADDED Requirements

### Requirement: Карточка внешней сущности — приборная отделка только для чтения

Для внешней зарегистрированной сущности предпросмотр SHALL показывать собранную источником карточку: имя, тип-заголовок общего вида («Карточка: <тип>»), строку источника, текстовые блоки и связи с другими записями, переход по которым кликом открывает ту же колонку предпросмотра. Редактируемых контролов, полей дат/рейтинга ядра и кнопки генерации в такой карточке быть НЕ SHALL; отсутствие поля источника (например, SRD-текста заклинания) SHALL выражаться честной строкой-пояснением, а не пустым блоком.

#### Scenario: Черта показана собранной

- **WHEN** в предпросмотре открыта запись «черта» подключённого датасета
- **THEN** видны имя, тип, источник и текст черте; контролов правки нет

#### Scenario: Переход по связи записи

- **WHEN** в карточке подкласса кликнут связанный класс
- **THEN** в колонке открылась карточка этого класса
