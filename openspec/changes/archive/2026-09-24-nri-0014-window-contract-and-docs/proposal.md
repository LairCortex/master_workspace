# Proposal: nri-0014-window-contract-and-docs

## Why

Живые аудиты 2026-09-24 зафиксировали системный паттерн «sheet вместо окна»: `dialog.open()` с parent на macOS даёт неперемещаемый лист без заголовка с блокировкой меню — и ломает как заявленную модаленость («Сменить игру» модален вопреки комментарию, A1), так и заявленную не-модаленность (календарь/документы блокируют всё меню, AB3). Прослеживаемо страдает и содержимое: документация/Changelog не прокручиваются ничем — доступно 2–16 % текста (AB1), у карточки документа нет ни заголовка, ни подсказанного закрытия (AB2), повторный пункт открывает дубль листа (AB4). Внутренние листы событий/карточек не показывают, какой слой активен (E1/CR5). Завершает картину английское оперение нативных попапов (`OK/Cancel/Yes/No`, `Save As:`) в полностью русском интерфейсе (L1, паттерн №2 аудитов). Требуется не точечная латка, а норма формата с приёмкой.

## What Changes

- **Норма «формат на вход»** (реестр grill-сессии, попадёт в спеку): лаунчер первого запуска — модалка; «Сменить игру»/Документация/Changelog/Настройка LLM — не-модальные окна с заголовком и крестиком; «Календарь…»/импорт xlsx — модално, но с активной точкой выхода в теле; EventDialog/карточка — листы с внутренним заголовком. Семантика: не-модально := `NonModal` + живое меню; модално := в теле есть работающая кнопка выхода (не только Esc).
- **Реестр открытых menu-окон**: повторный пункт меню поднимает существующее окно вместо создания второго (единый механизм вместо патча по местам); README и Changelog — разные окна, каждое в единственном экземпляре (AB4).
- **DocViewer**: прокручиваемый документ (`ScrollView` вокруг текстового поля — образец `SheetPresetRoot.qml`), шапка с названием документа и кнопкой закрытия (AB1, AB2), как не-модальное окно с настоящей шапкой вместо sheet-карты (AB3).
- **Внутренние листы**: `EventDialog`/карточка сущности получают видимую строку заголовка (текст + крестик = тот же результат, что Esc/Отмена, E1); нижний лист в стеке затемняется сильнее — глубина читается (CR5).
- **Лаунчер из «Сменить игру…»**: не-модальное окно с заголовком вместо titlebar-less sheet (A1, A2); пункт получает «…» — гарантированный диалог (A3).
- **Вёрстка листов настроек**: устранены мёртвые зоны листа xlsx-импорта (D5, ~116/110 pt невидимых слот-занятых блоков); лист мастера не шире родителя, скачка окна нет (D6).
- **Русский язык системного оперения**: стандартные кнопки/кнопки `QDialogButtonBox`/`QMessageBox` — `OK/Cancel/Yes/No` становятся «ОК/Отмена/Да/Нет» через `QTranslator` с `qtbase_ru.qm` в бандле; файловые диалоги — не-нативные (qt-панель), локализуемые целиком и одинаковые на dev и в `.app` (L1).
- Оффскрин-пины: формат/модаленость (`windowModality` + наличие кнопки), реестр (второй вызов не создаёт окно), скролл DocViewer, тексты кнопок; живой ре-аудит — финальным таском.

## Capabilities

### New Capabilities
- `document-viewer`: просмотр встроенных документов приложения (README, CHANGELOG): прокручиваемость, опознаваемость документа (заголовок), формат окна (не-модален, единственный экземпляр каждого документа).
- `interface-language`: интерфейс приложения един — русскоязычный: стандартные элементы Qt-диалогов и файловые панели показываются по-русски и на dev-запуске, и в собранном приложении.

### Modified Capabilities
- `qml-shell`: контракт формата диалогов (вход→окно/лист, семантика модальности с точкой выхода), реестр открытых menu-окон с повторным подъёмом, внутренний заголовок и различимая глубина стека островных листов, живая вёрстка островных листов без мёртвых зон и превышения родителя.
- `game-launcher`: лаунчер из «Сменить игру…» — не-модальное окно с видимым заголовком; модален только первичный выбор игры.
- `qml-components`: компонент строки заголовка листа (название + кнопка закрытия) с именем/ролью в дереве доступности.

## Impact

- `app/presentation/`: `main_window.py` (пункты и показ окон, `…` у A3), `main.py` («Сменить игру»), `doc_viewer_dialog.py` + `qml/DocViewerRoot.qml` (скролл/шапка/формат), `event_dialog.py`/`entity_card_dialog.py` + корни QML (заголовок, затемнение), `XlsxImportRoot.qml` (мёртвые зоны), новый `nri/components/ThemeSheetHeader.qml` + `qmldir`, реестр окон в `presentation/wiring.py` (или рядом); правки мест `.open()`/`.show()`.
- `app/main.py`/`app/infrastructure/`: `QTranslator` на старте; `qmake6 -_TRANSLATIONS`/`QLibraryInfo` — поставка `qtbase_ru.qm` в `nri_manager.spec` (datas).
- Тесты: новые оффскрин `tests/presentation/` (формат/реестр/скролл/язык), правка существующих на новых модаленостей.
- Документация: блок AGENTS про computer-use (норма формата — что живьём ждём от окон), `docs/functional-checklist.md`, `docs/CHANGELOG.md`; карта — `docs/design-review-roadmap.md`.
- Схема БД, формат архива, протокол «Стола» — не затронуты. Видимые тексты и поведение листов мышью сохраняются (добавляется заголовок/кнопки там, где их не было).
