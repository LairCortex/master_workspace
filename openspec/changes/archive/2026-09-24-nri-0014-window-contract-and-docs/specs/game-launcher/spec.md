## ADDED Requirements

### Requirement: Формат лаунчера зависит от точки входа

Лаунчер SHALL быть модален при первом выборе игры (приложения без открытой игры ещё нет) и SHALL быть не-модальным окном с видимым заголовком, когда открывается из «Сменить игру…» главного окна: при открытом лаунчере SHALL оставаться возможным закрыть окно без смены игры, остальное меню приложения SHALL не быть погашенным этим лаунчером.

#### Scenario: Смена игры без блокировки

- **WHEN** из «Сменить игру…» открыт лаунчер
- **THEN** видно заголовок окна и кнопку закрытия; закрытие возвращает в ту же игру без изменений

#### Scenario: Первый запуск остаётся модальным

- **WHEN** приложение запущено без открытой игры
- **THEN** лаунчер модальный выбор игры, без него пользователь в приложение не попадает
