# Proposal: add-character-sheet-a1

## Why

Мастеру нечем спроектировать лист персонажа под свою систему и оставить макет в файле игры. Это первый тонкий срез эпика «чар-листы» (A1): чертёж шаблона на одной книжной A4, без заполнения персонажа, PDF, пресетов и сети. Предыдущий слет (NRI-0007) не воскрешаем — скоуп специально узкий, чтобы не взять редактор целиком.

## What Changes

- Новый пункт меню **«Чар-листы»**: список шаблонов текущей игры (создать / открыть / переименовать / удалить) и одно окно редактора.
- Шаблон хранится в `game.db` текущей игры: имя уникально в игре, `schema_version = 1`, стабильные id полей, одна книжная страница A4.
- Редактор — чертёж, не заполнение: три типа полей (подпись, однострочное, многострочное) как раздельные объекты; постановка разовым кликом; move/resize/delete; инлайн-правка текста даблкликом и в панели свойств.
- Явное «Сохранить», dirty-флаг, подтверждение при закрытии / смене игры / открытии другого шаблона. Создание сразу пишет пустой шаблон в БД.
- В CHANGELOG помечается как незавершённое; пункт меню виден. В пользовательский релиз эпик не входит, пока нет хоста (D) — это не скоуп A1.

Не входит (следующие куски эпика): вторая страница и альбомная ориентация, undo/snap/z-order, PDF, JSON-обмен шаблонов, пресеты систем, экземпляр/заполнение персонажа, LAN-хост.

## Capabilities

### New Capabilities

- `character-sheet-storage`: CRUD шаблонов в базе текущей игры, уникальность имени, схема страницы/полей (`schema_version`, стабильные id), немедленное переименование, запрет удаления открытого шаблона.
- `character-sheet-editor`: канвас одной книжной A4, три типа полей, постановка/выделение/геометрия, инлайн-правка и панель свойств, dirty/сохранение, одно окно редактора, зум.

### Modified Capabilities

- (нет) Экспорт `.nri` не меняет формат: шаблоны лежат в `game.db` и уезжают с игрой как часть архива v2. Отдельное требование в `game-archive` не нужно.

## Impact

- Схема: новая таблица `character_sheets` через `create_all` в `init_db()` (новая таблица на существующих БД появляется при старте; ALTER существующих таблиц не требуется).
- Новые модули: domain (шаблон/поле/типы), repository, `CharacterSheetService`, viewmodel, views (список, редактор, канвас, палитра, панель свойств).
- `app/main.py` / `MainWindow`: меню «Чар-листы», DI, закрытие редактора и списка при смене игры.
- Тесты: domain/service/repo + виджеты (offscreen Qt) + E2E списка и редактора. Без сети.
- `docs/CHANGELOG.md`: запись с пометкой незавершённого.
- Зависимости: без новых runtime-пакетов (канвас — Qt `QGraphicsView`).
