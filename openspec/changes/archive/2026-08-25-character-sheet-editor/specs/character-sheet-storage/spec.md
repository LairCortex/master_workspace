## Purpose

Хранение шаблонов чар-листов в базе текущей игры и обмен шаблонами как переносимыми JSON-файлами: создание, список, уникальность имён, стабильные идентификаторы полей и экспорт проекта.

## ADDED Requirements

### Requirement: Хранение шаблонов в базе игры

Шаблоны чар-листов SHALL храниться в базе данных текущей игры. Шаблон SHALL включать: имя, общую ориентацию, упорядоченный список страниц (каждая страница — имя и список полей) и, для каждого поля, тип, геометрию (позиция и размеры), подпись, значение по умолчанию, размер шрифта и типоспецифичные свойства. При создании поле SHALL получать стабильный идентификатор, который не меняется в дальнейшем и используется как имя соответствующего поля при экспорте в PDF.

#### Scenario: Сохранение и перечитывание шаблона

- **WHEN** сохранённый шаблон открывается заново
- **THEN** все страницы, поля, их геометрия, свойства и порядок восстановлены идентично сохранённому состоянию

#### Scenario: Стабильность идентификаторов

- **WHEN** шаблон сохраняется, открывается и сохраняется повторно без удаления полей
- **THEN** стабильные идентификаторы полей не изменяются

### Requirement: Уникальность имени шаблона

Имя шаблона SHALL быть уникальным в пределах одной игры. Создание шаблона с именем, совпадающим с существующим, SHALL отклоняться с сообщением пользователю.

#### Scenario: Повторное имя отклонено

- **WHEN** пользователь создаёт шаблон с именем уже существующего шаблона этой игры
- **THEN** создание не происходит, пользователю сообщается о конфликте имён

#### Scenario: Разные игры

- **WHEN** шаблон с данным именем существует в другой игре
- **THEN** создание шаблона с тем же именем в текущей игре допускается

### Requirement: Вхождение в экспорт игры

Шаблоны чар-листов SHALL входить в экспорт игры (.nri) вместе с базой и восстанавливаться при импорте игры.

#### Scenario: Экспорт и импорт игры

- **WHEN** игра с шаблонами чар-листов экспортирована и импортирована
- **THEN** все шаблоны, страницы и поля присутствуют в импортированной игре без потери данных

### Requirement: Экспорт проекта в JSON

Шаблон SHALL экспортироваться в единый JSON-файл, содержащий метку формата и версии формата, название шаблона, ориентацию, страницы и поля со всеми свойствами и стабильными идентификаторами.

#### Scenario: Экспорт корректного проекта

- **WHEN** пользователь экспортирует шаблон в JSON
- **THEN** создается файл, содержащий полный шаблон и метку формата/версии

### Requirement: Импорт проекта из JSON

Импорт JSON-проекта SHALL создавать новый шаблон в текущей игре. Если файл не является корректным JSON-проектом (неверная структура, незнакомая версия формата), импорт SHALL отклоняться с сообщением о причине, не создавая шаблон. При совпадении имени с существующим шаблоном импорт SHALL создавать шаблон с отличающимся (суффиксированным) именем, а не перезаписывать существующий.

#### Scenario: Успешный импорт

- **WHEN** импортирован корректный JSON-проект шаблона
- **THEN** в игре появляется новый шаблон с восстановленными страницами, полями, свойствами и стабильными идентификаторами

#### Scenario: Повреждённый файл

- **WHEN** импортируется файл, не являющийся корректным проектом шаблона
- **THEN** импорт отклонён, шаблон не создан, пользователю показана причина

#### Scenario: Конфликт имён при импорте

- **WHEN** имя импортируемого шаблона совпадает с существующим
- **THEN** создаётся новый шаблон с отличающимся именем, существующий шаблон не изменён
