# Proposal: add-game-calendar-core

## Why

Календарь игры должен стать настраиваемым (свои месяцы, недели, вставные дни), но главная неясность — арифметика соответствия «координата ⟷ порядковый день» для произвольного календаря — сейчас снимается только «в бою», внутри приложения. Кусок C0 дорожной карты кастомного календаря (`docs/custom-calendar-roadmap.md`) снимает её заранее: прототип арифметического ядра `GameCalendar` с тестами, до первого изменения приложения.

## What Changes

- Новая общая арифметическая модель даты игрового мира: координата (год, месяц, день либо вставной день) ↔ монотонный целочисленный ключ, годовой недельный цикл заданной длины, BC-зеркало по длине игрового года.
- Новый протокол `GameCalendar` (`to_key`, `from_key`, `weekday`, `month_length`, `is_valid`, `validate`) с двумя реализациями:
  - `StandardCalendar` — действующая григорианская формула, ключ побитово совпадает с нынешним `era_key` (гарантия «старые игры молча живут»);
  - `CustomCalendar` — спека с фиксированными длинами месяцев, длиной недели на выбор и списком вставных дней.
- Новая структура спеки кастомного календаря (месяцы «имя+длина», неделя «имена», вставные дни «имя, после месяца M») с валидацией, возвращающей список причин.
- Тестовый текстовый предпросмотр годового календаря (месяцы, недели, плашки вставных дней) — помощник для глазамиой проверки и будущей сверки с сеткой C3.
- Приложение НЕ меняется: файл ядра никем не импортируется до C1; схему БД, настройки, UI и импорт XLSX это изменение не затрагивает.

## Capabilities

### New Capabilities

- `game-calendar-core`: арифметическое ядро игрового календаря — координата ⟷ порядковый ключ, длины месяцев, вставные дни вне недельного цикла, непрерывный недельный цикл, BC-зеркало; обе реализации (стандартная и кастомная), валидация спеки, предпросмотр года.

### Modified Capabilities

(нет — существующие требования `date-eras` в C0 не меняются; `era_key` остаётся действующим, совпадение ключей `StandardCalendar` с ним проверяется тестами как новое собственное требование capability `game-calendar-core`.)

## Impact

- Новый код: `app/domain/game_calendar.py` (ядро; приложением пока не используется).
- Новые тесты: `tests/domain/test_game_calendar.py` (золотое совпадение со старым ключом, круговой обход, fuzz-свойства, отбраковка спеки, предпросмотр).
- Зависимости: нет новых.
- Миграции БД, настройки, UI: не затрагиваются (C1+).
- Дальнейшие куски: C1 подключает ядро к `era_key`/хукам/бэкфиллу; C3 сверяет предпросмотр с виджет-сеткой; спецификация сохраняется в `specs/game-calendar-core/spec.md`.
