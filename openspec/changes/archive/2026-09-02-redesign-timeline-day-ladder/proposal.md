# Proposal: redesign-timeline-day-ladder

## Why

Текущая шкала таймлайна («одна позиция = один день, многодневки — скобкой на рейке») оказалась неудобной: событие не видно в дни своего протекания, навигация по датам (рейка, кнопки сутки/месяц/год, группировка) не оправдывает себя, а пустые дни не дают точки входа для создания события. Решено перестроить ленту в sticky-заголовки периодов с дублированием многодневных событий по дням и навигацией колесом.

## What Changes

- **BREAKING** Лента дней: sticky-заголовок на день, под ним пул карточек событий дня; многодневное и бессрочное событие **дублируется карточкой в каждый день** своего протекания (в данных — одна запись, правки действуют на событие целиком).
- **BREAKING** Убрана рейка со всем её интерактивом (метки, скобки, засечки, клик-прыжок, drag диапазона) и убрано растягивание окончания за засечку.
- **BREAKING** Drag&drop переработан: карточка тянется целиком; на отпускании в другой день — контекстное меню у курсора «Перенести» / «Расширить» (расширить = сдвинуть границу события к дню дропа: вниз → `end := день`, вверх → `start := день`; перенос = старт := день дропа, длина сохраняется).
- **BREAKING** Пустой день — строка-плейсхолдер «нет события» с inline-созданием (иконка «+» + название + Enter); провалы без событий длиннее 14 дней схлопываются в одну строку (клик = предзаполненный «выбор даты»); перетаскивание на схлопнутый провал запрещено.
- **BREAKING** Ступени сутки/месяц/год: кнопки-переключатели удалены; зум только Alt/Opt + колесо с якорем от позиции курсора (карточка → её день, заголовок → день заголовка). На уровнях месяц/год — sticky-заголовок периода + clickable-карточка «N событий» / «нет событий», клик проваливает на ступень вниз с установкой окна периода.
- **BREAKING** «Бессрочные» события (`end_date = None`) отображаются карточкой от старта до дна ленты с пометкой «бессрочно»; дно ленты = max(самая поздняя закрытая дата окончания, старт бессрочного + 1 год); перенос за дно отодвигает дно.
- Чип-фильтр «Все даты» переосмыслен в кнопку **«Выбор даты»**: выставленное окно ограничивает ленту (навигация), провал по уровням прописывает окно; фильтр как отдельная функция отсутствует. Нижняя граница календаря — 0100 год (как сейчас), верхней — 9999.
- **BREAKING** Удалена группировка по сущностям на таймлайне (переключатель, секции, код `EntityKind`/`group_by`/`_group_map`/`build_event_groups` — вне таймлайна не используется).
- Новая кнопка **«Скрыть даты без событий»**: скрывает пустые дни, схлопнутые провалы и пустые карточки месяцев/годов на любом уровне; по умолчанию выключена, состояние только сессии.
- Sticky-заголовок при прокрутке плавно выталкивается новым (push-out).
- Клик по карточке события сохраняет текущее поведение: одиночный — выбор/панель деталей, двойной — редактор. Модель события не меняется.

### Modified Capabilities

- `event-timeline`: переписывается поведение шкалы — лента дней с sticky-заголовками и дублированием многодневок по дням; удаление рейки и её жестов; drag «перенести/расширить» с контекстным меню; inline-создание из пустого дня; схлопывание провалов; зум Alt/Opt+колесо с проваливанием по уровням периодов; «Выбор даты» вместо чип-фильтра; кнопка «Скрыть даты без событий»; удаление группировки по сущностям; новые границы диапазона ленты при бессрочных событиях.

## Impact

- `app/presentation/views/timeline_widget.py` — перестройка виджета/делегата (рейка, скобки, serif-жесты, переключатели удаляются; sticky push-out, inline-строка, контекстное меню дропа добавляются).
- `app/presentation/views/timeline_rows.py` — ядро строк: дублирование событий по дням, уровни периодов с карточками-счётчиками, схлопывание провалов; удаление `groups`/`NO_GROUP_KEY`, вспомогательного кода засечек.
- `app/presentation/viewmodels/timeline_viewmodel.py` — удаление `EntityKind`/`group_by`; новые состояния (ступень от зума, окно «выбора даты», тумблер скрытия); новый сигнал коммита дат.
- `app/application/wiring.py` — проводка нового сигнала переноса/расширения и inline-создания.
- Тесты: `tests/presentation/test_timeline_widget.py`, `test_timeline_scale_widget.py`, `test_viewmodels.py`, `tests/ui/test_e2e_timeline_*` — ревизия/частичное удаление (группировка, рейка, засечки).
- Модель данных, БД и миграции не меняются.
