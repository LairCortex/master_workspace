# Proposal: Переезд шкалы событий в QML-остров (Q2.5a)

## Why

Эпик Q требует, чтобы всё содержимое окон жило QML-островами при нативном шелле; шкала событий — последний widgets-контент в главном окне между уже QML-панелями (после Q2b), и пока она нативная, эпикvisually расслоен: два скина и два live-retheme-пути в одном прямоугольнике сплиттера. Переезд закрепляет инфраструктуру Q1/Q2a1 на самом интерактивном экране приложения (лестница, drag-жесты, sticky, попапы) и закрывает промежуточное состояние «widgets-шкала между QML-панелями», ради которого Q2.5 и задуман.

## What Changes

- Панель шкалы событий (шапка + лента) переезжает в QML-остров `QQuickWidget` внутри прежнего слота `QSplitter`; нативные шелл-контейнеры не трогаются. **Widgets-реализация `TimelineWidget`/`TimelineListView`/делегата удаляется целиком, флага/второй копии нет** (прецедент Q1).
- Поведение не меняется ни на пункт: базовая линия переноса — действующий спек `event-timeline` (лента-лестница после redesign: sticky-заголовки с выталкиванием, дубли многодневок, схлопнутые провалы, бессрочные до дна ленты, «Выбор даты», «Скрыть…», Alt/⌥+колесо с якорем, drill, drop-меню жестов, инлайн-создание, jump-кнопки). `event-timeline` остаётся чек-листом приёмки и не правится.
- qt-нулевое ядро `timeline_rows.py` — единственный источник геометрии/правил; JS-дубликатов расчётов не заводится. Список строк питается в QML списочной моделью (ленивая поставка, переиспользование делегатов), копии событий в острове нет.
- Python-фасад панели сохраняет публичные методы и сигналы текущего виджета (`update_events`, `set_selected`, `scroll_to_event`, jump'ы, `cover_window_for_span`; `event_selected`, `event_double_clicked`, `event_dates_moved`, `window_changed`, `event_create_requested`, …) — wiring не переписывается под новый контракт.
- Выпадающие подсказки островов получают нативный шим (объявление текста в QML, отрисовка единственным `QToolTip` через Python-сторону); переносится вся шестёрка подсказок шкалы, включая динамическую подсказку карточки.
- Поповер «Выбора даты» остаётся единственным скинутым widgets-поповером (вызов сигналом из QML — по образцу tooltip-шима; QML-поповер обрезался бы прямоугольником острова); меню («+», drop-меню жеста) — нативные `QMenu` по действующему правилу системных попапов.
- Долг W5 (молчаливый сбой сохранения диалогов) гасится предыдущим куском `fix-silent-dialog-save-debt` и здесь не упоминается.
- Диалоги `event_dialog`/`entity_card_dialog` и `MentionTextEdit` не переезжают (решение grill 2026-09-03: QML не умеет редактирования богатого текста); в дорожной карте им — отдельный заблокированный пункт вне порядка.
- Сборка/тесты: `.spec` получает новые qml-файлы (datas, по образцу Q2a1); приёмка — по Requirement'ам `event-timeline` через адресацию по `objectName`, пиксельная тематическая приёмка и live-retheme сохраняются; Qt-нулевые юниты ядра не трогаются; внутренностные widget-тесты удаляются вместе с виджетом.
- `docs/design-system-roadmap.md`: текст Q2.5 переписывается под фактический состав (шкала + долг; диалоги — заблокированный пункт вне карты).

## Capabilities

### New Capabilities

_(нет — наблюдаемое поведение шкалы описано неизменным `event-timeline`; меняется способ его поставки)._

### Modified Capabilities

- `qml-shell`: «QML-каркас приложения» — острова допускаются в содержательные панели главного окна (шкала событий перестаёт быть widgets, канвас/mention-edit/диалоги остаются; формулировка «шкала событий остаётся widgets» из спека снимается); новый контракт «питание QML-списков списочной моделью из VM поверх qt-нулевого ядра»; новое правило «нативный шим всплывающих подсказок для QML-островов».
- `qml-components`: «Библиотека QML-компонентов chrome» — библиотека дополнительно предоставляет объявление подсказки (прикреплённое свойство) для tooltip-шима; остальное без изменений.

## Impact

- `app/presentation/views/timeline_widget.py` — удаление; поповер календарей переезжает в отдельный файл Python-стороны острова; `tests/presentation/test_timeline_widget.py` и внутренностные соседние тесты удаляются/переписываются.
- `app/presentation/qml/` — `TimelineRoot.qml` (+ локальные делегат-файлы шкалы); `nri/components` — tooltip-шим (новый тип qmldir-модуля).
- `app/presentation/viewmodels/timeline_viewmodel.py` — списочная модель строк поверх `timeline_rows.py`; sync-инвайкейблы (sticky-расчёт, jump-индексы, drill/level); контракт существующих property/сигналов не меняется.
- `app/presentation/views/` — Python-фасад острова (`QQuickWidget`-обёртка с прежним публичным API панели; контекст: VM + `islandPalette`); `main.py`/`main_window.py` — точка конструирования панели.
- Проводка: `wiring.py` — сигнальный контракт не меняется (ожидается diff только по импортам/атрибутам); долг-правки из предыдущего куска остаются как есть.
- `nri_manager.spec` (datas + новые qml-файлы), `tests/` (перенос приёмки, бандл-тест), `docs/CHANGELOG.md`, `docs/design-system-roadmap.md`.
- БД, миграции, модель событий, `event-timeline`/`event-types` спеки — без изменений.
