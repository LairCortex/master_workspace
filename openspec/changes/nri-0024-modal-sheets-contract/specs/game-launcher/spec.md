## ADDED Requirements

### Requirement: Смена игры открывается лаунчером-листом

Лаунчер при выборе из «Сменить игру…» SHALL быть листом внутри главного окна: шапка «Сменить игру…», кнопка закрытия и Esc возвращают в ту же игру без изменений; пока лист открыт, остальное содержимое главного окна заблокировано. Подтверждение выбора SHALL закрыть лист и пересобрать главное окно под выбранную базу без перезапуска приложения; охрана несохранённых изменений перед переключением SHALL остаться прежней.

#### Scenario: Смена игры без потери игры

- **WHEN** из «Сменить игру…» открыт лист и закрыт без выбора
- **THEN** лист закрылся, приложение осталось в той же игре без изменений

#### Scenario: Подтверждение пересобирает главное окно

- **WHEN** в листе смены игры выбрана другая игра и подтверждена, несохранённых изменений нет
- **THEN** лист закрылся, то же окно приложения показывает данные выбранной базы, перезапуска процесса не было

### Requirement: Первый экран остаётся модальным

Лаунчер SHALL быть модален при первом выборе игры: приложения без открытой игры ещё нет, без выбора игры пользователь в приложение не попадает.

#### Scenario: Первый запуск остаётся модальным

- **WHEN** приложение запущено без открытой игры
- **THEN** лаунчер модальный выбор игры, без него пользователь в приложение не попадает

## REMOVED Requirements

### Requirement: Формат лаунчера зависит от точки входа

**Reason**: Немодальное окно смены игры упразднено контрактом трёх классов: смена игры стала листом внутри главного окна, модален первого экрана переиздан отдельным требованием.

**Migration**: Тот же пункт «Файл → Сменить игру…» открывает лист (требование «Смена игры открывается лаунчером-листом», прежний сценарий закрытия без смены сохранён в нём); модален первого запуска закреплён требованием «Первый экран остаётся модальным».
