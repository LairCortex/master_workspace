# Proposal: nri-0024-modal-sheets-contract

## Why

Форматы окон заданы точкой входа (NRI-0014), но на практике приложение говорит на трёх языках: листы с шапкой и затемнением (событие, карточка), модальные окна системы («Календарь…», просмотр изображения) и девять немодальных окон («Обзор мира», документы, LLM, чар-листы, «Стол»). Дизайн неоднороден, поведение при смене фокуса и закрытии различается, а два просмотрщика и подбор привязки живут на блокирующих вызовах — опасном приёме на qasync-петле (FI-6). Владелец решил: единой нормой становится лист-оверлей (эталон — «Редактировать событие»), немодальными остаются только первый экран выбора игры и главное окно; рабочие окна чар-листов — единственное осознанное исключение-окно.

## What Changes

- **Три класса окон вместо разнобоя.** 1) немодальные: первый экран выбора игры и главное окно; 2) листы — весь остальной контент; 3) зафиксированные исключения: окна чар-листов, мелкие системные диалоги Qt (файлы, имена, подтверждения, сообщения) и всплывашки (календарь-сетка, часы, упоминания, меню, подсказки).
- **Немодальные окна становятся листами:** «Обзор мира», «Документация», «Changelog», «Настройка LLM…», «Сменить игру…». Параллельный просмотр контента рядом с работой уходит осознанно — состояние не теряется, повторный вход мгновенен.
- **Старые модалы перешиваются в листы:** «Настройка календаря» (лист на всю ширину главного окна с прокруткой), «Просмотр изображения», подбор «Выберите …» при привязке. Блокирующие показ-вызовы на qasync-петле убираются.
- **«Сменить игру…»** — лист с содержимым лаунчера; подтверждение пересобирает главное окно под выбранную игру без перезапуска приложения, охрана несохранённого та же.
- **«Стол» — лист-пульт с отвязанной сессией:** закрытие листа НЕ останавливает стол (останов — явная кнопка; при смене игры/выходе — без вопроса). Пока стол поднят, в правом верхнем углу главного окна (в одном ряду с датой «сейчас») живёт кластер: метка «Стол · N игроков» (открывает пульт) и кнопка «Остановить стол»; кластер читается и нажимается поверх затемнения любого листа. Быстрый доступ к листам игроков — из пульта: клик по игроку поднимает его окно «Лист» (исключение, read-only при поднятом столе; живое окно поднимается вместо второго).
- **Меню при открытом листе:** пункты, открывающие листы, неактивны; пункты исключений (окна чар-листов) доступны всегда.
- **Стек листов без искусственного предела** (каскад затемнения считается по цепочке): событие → карточка → изображение — штатно.
- **Размеры листов:** фиксированный размер по умолчанию (теперешний размер окна), рост вместе с главным окном до предела контента, скролл вместо обрезания; размещение листы не помнят.
- **Визуальное единообразие листов:** «Типы событий» и «Импорт из .xlsx» получают недостающую шапку `ThemeSheetHeader` (заголовок + «Закрыть» = исход Esc).
- **Уборка наследия:** роли памяти окон `world_snapshot` и `table_host` упраздняются (остают `main`, `sheet_list`, `sheet_editor`, `sheet_fill`); реестр «живое окно вместо второго» для пунктов меню упраздняется — дедупликация окон чар-листов остаётся своим единственным механизмом.
- Мастер календаря первого запуска новой игры открывается листом поверх уже показанного главного окна (следствие: окно появляется раньше мастера; блокировка работы листом сохраняется).
- Без изменений: первый экран выбора игры, главное окно, чар-листы (окна, размещение помнится), системные диалоги Qt и всплывашки, формат данных, `.nri`-экспорт/импорт.

## Capabilities

### New Capabilities

- `modal-sheets`: контракт трёх классов окон — что такое лист (шапка, затемнение, Esc, стек, размеры без памяти размещения), что остаётся окном-исключением, поведение меню и живого кластера стола при открытом листе, запрет блокирующего показа диалогов на qasync-петле.

### Modified Capabilities

- `qml-shell`: контракт формата окон «задан точкой входа» заменяется трёхклассовым (лист — норма); требование дедупликации «повторный выбор поднимает живое окно» через реестр меню упраздняется вместе с самим реестром.
- `main-window`: память размещений сжимается до главного окна и трёх окон чар-листов; роли «стол» и «обзор мира» упраздняются.
- `game-launcher`: «Сменить игру…» — лист внутри главного окна вместо немодального окна; подтверждение пересобирает главное окно без перезапуска.
- `document-viewer`: не-модальные окна документов становятся листами; единственный экземпляр больше не требуется (лист однократен по природе).
- `llm-configuration`: диалог настройки LLM становится листом; «Закрыть» и блокировка на время сохранения сохраняются.
- `calendar-wizard`: мастер — лист внутри главного окна (ширина окна, прокрутка); первый запуск новой игры показывает сначала главное окно, затем лист мастера.
- `world-snapshot`: обзор мира живёт листом вместо отдельного окна; роль размещения `world_snapshot` упраздняется; повторный вызов не множит copies (лист однократен).
- `image-display`: просмотр оригинала — лист поверх открывшего его окна/листа вместо модального окна; прокрутка и Esc сохраняются.
- `xlsx-import`: лист импорта получает шапку `ThemeSheetHeader` с заголовком и «Закрыть» вместо выхода только кнопкой «Отмена» в теле.
- `event-types`: лист типов событий получает шапку `ThemeSheetHeader` с заголовком и «Закрыть».
- `character-sheet-host`: панель стола становится листом-пультом; закрытие листа не останавливает стол (подтверждение «Остановить стол?» при закрытии упраздняется, останов явный); при поднятом столе в шапке главного окна живёт кластер «Стол · N игроков» + «Остановить стол», доступный поверх затемнения листа; клик по игроку в пульте поднимает его окно «Лист».

## Impact

- **Представление:** `MenuWindowRegistry` упраздняется; `sheet_windows.py`/`ApplicationWiring` — показ переведённого контента листами (`IslandDialogMixin` + `open()`); `ThemeSheetHeader` для xlsx/event-types; `WorldSnapshotWindow`/`DocViewerDialog`/`LlmSetupDialog`/`CalendarWizardDialog`/`ImageViewerDialog` переезжают в листы; лаунчер смены игры — лист с пересборкой `MainWindow`; просмотрщик изображений и подбор привязки теряют `exec()`; `SearchBar` — живой кластер стола поверх затемнения; `TableHostPanel` — содержимое в листе, сессия уже живёт отдельно (сервис не меняется); `geometry_memory.py` — роли `world_snapshot`/`table_host` удаляются.
- **Проводка и точка сборки:** обработчики «Сменить игру…» (пересборка главного окна вместо перезапуска-показателя), деактивация открывающих действий меню при открытом листе.
- **Настройки:** устаревшие ключи `world_snapshot`/`table_host` в `~/.nri_manager/ui.json` молча игнорируются (список ролей — код, чистка файла не нужна).
- **Тесты и документация:** 100 % покрытие новых строк; пины формата окон (лист vs исключение), живого кластера, однократности листов, пересборки главного окна; guard-тесты доступности листов по контракту островов; переписываются AGENTS.md (окно-формат норма), CHANGELOG, контракт живого аудита окон.
- **Данные:** нет миграций; формат `.nri`, календарь, черновики не меняются.
