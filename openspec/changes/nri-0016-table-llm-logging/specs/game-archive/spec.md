## ADDED Requirements

### Requirement: Диалог эксппорта открывается у каталога игр

«Экспорт игры…» SHALL открывать панель сохранения с初始ной директорией, содержащей базу текущей игры (каталог `games/`), и предлагаемым именем `<игра>.nri`; пользователь SHALL мочь сохранить архив рядом с источником без ручного перехода.

#### Scenario: Экспорт рядом с играми

- **WHEN** вызван «Экспорт игры…» в каталоге ` games/Dungeon/`
- **THEN** панель открыта в каталоге игр, предзаполнено имя `Dungeon.nri`
