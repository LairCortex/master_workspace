## Purpose

Версия приложения для пользователя: где её видно без чтения файлов и какой источник номера единственный для интерфейса.

## ADDED Requirements

### Requirement: Версия видима в интерфейсе

Меню «О приложении» SHALL содержать неактивную строку вида «Версия X.Y.Z», показываемую всегда; источник номера для интерфейса SHALL быть один (модульная константа версии), SHALL не выбираться из `Changelog` и не печататься литералом в меню.

#### Scenario: Посмотреть версию без открытия документов

- **WHEN** пользователь открыл меню «О приложении»
- **THEN** строка «Версия X.Y.Z» видна и неактивна

#### Scenario: Номер не раздваивается

- **WHEN** сборка подготовлена к релизу
- **THEN** версия в строке меню равна версии пакета и верхней записи журнала изменений (проверяется автоматическим тестом)
