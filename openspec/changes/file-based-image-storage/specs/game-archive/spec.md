## Purpose

Формат переносимого архива игры `.nri` версии 2: в архив входят база и полное дерево изображений; импорт атомарен и верифицируется по sha256; сохранена совместимость с архивами версии 1.

## ADDED Requirements

### Requirement: Состав экспортного архива v2

Экспорт игры SHALL создавать ZIP-архив `.nri`, содержащий на корне `game.db`, полное дерево `images/` игры (оригиналы и preview) и `meta.json` с именем игры, меткой версии приложения, полем `archive_version: 2`, датой экспорта и размером базы. Состав архива соответствует каталогу игры один-в-один.

#### Scenario: Экспорт игры с изображениями

- **WHEN** экспортирована игра, у которой есть images
- **THEN** архив содержит `game.db`, все файлы `images/` и `meta.json` с `archive_version: 2`

#### Scenario: Экспорт игры без изображений

- **WHEN** экспортирована игра без изображений
- **THEN** архив содержит `game.db` и `meta.json` с `archive_version: 2`; отсутствие файлов изображений допустимо

### Requirement: Атомарный верифицируемый импорт

Импорт архива SHALL происходить в два этапа: распаковка во временное хранилище и проверка sha256 каждого файла `images/` (хэш сверяется с именем файла), после чего распакованное дерево атомарно перемещается в каталог игр. При любой ошибке (неверный формат, сбой верификации, сбой переименования) импорт SHALL не оставлять частичных данных в каталоге игр и SHALL сообщать о причине. Импорт в игру с существующим именем SHALL отклоняться без изменения существующей игры.

#### Scenario: Успешный импорт

- **WHEN** импортирован корректный архив v2
- **THEN** в каталоге игр появляется новая игра с базой и изображениями, все файлы проходят проверку sha256

#### Scenario: Повреждённый файл в архиве

- **WHEN** sha256 какого-либо файла `images/` в архиве не совпадает с его именем
- **THEN** импорт отменяется, ни одного файла не появляется в каталоге игр, пользователю сообщается о повреждённом файле

#### Scenario: Конфликт имён

- **WHEN** импортируется архив с именем игры, которая уже существует
- **THEN** импорт отклонён, существующая игра не изменена, временные данные удалены

### Requirement: Совместимость с архивами v1 и старые версии приложения

Архив v1 (без `images/`) SHALL успешно импортироваться: игра создаётся каталогом без файлов изображений, а legacy-base64 данные переносятся при первом открытии игры через миграцию (capability image-storage). Импорт архива v2 в старую версию приложения, не знающую v2, допускает потерю изображений (в базе остаются только данные без файлов) — ограничение закреплено как принятое.

#### Scenario: Импорт архива v1

- **WHEN** импортирован архив v1 (без `images/`)
- **THEN** игра создаётся, при первом открытии все legacy-изображения доступны как файлы

#### Scenario: Экспорт и повторный импорт

- **WHEN** экспортированная и затем импортированная игра открывается
- **THEN** все изображения доступны (оригинал и preview) и соответствуют исходным файлам по sha256
