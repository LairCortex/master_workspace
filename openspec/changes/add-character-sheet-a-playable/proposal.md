# Proposal: add-character-sheet-a-playable

## Why

A1 даёт одну книжную страницу и три текстовых типа — этого мало, чтобы нарисовать играбельный лист. Нужна выразимость: много страниц, закрытый каталог полей и проверка каждого типа тестами. Удобство редактора (undo, snap, z-order) — следующий кусок (A-editor), не этот.

Зависит от [`add-character-sheet-a1`](../add-character-sheet-a1/) (применять после A1). Возможности `character-sheet-*` ещё не в `openspec/specs/` до архива A1 — дельты этого change их расширяют.

## What Changes

- Страницы без лимита: рейка (имя, +, удалить, порядок) + канвас-лента A4 столбиком (как Word). Последнюю страницу удалить нельзя; непустую — с подтверждением.
- **BREAKING относительно A1-редактора:** колесо = скролл, Ctrl+колесо = зум; при открытии вписывается **ширина** листа, не вся страница.
- Одна ориентация на шаблон; переключатель книжная/альбомная зажимает поля, не масштабирует.
- Перетаскивание поля через зазор переносит его на другой лист (зажим по странице).
- Типы: чекбокс, дробное число (min/max, `,`→`.`), выпадающий список, картинка (ImageStore), декоративные рамка и осевая линия. Палитра расширяется. Нет таблиц, формул, repeating, rich text, радио, часов.
- `schema_version = 2`; чтение v1 без потери; неизвестный тип — отказ открыть.
- Картинка шаблона — ссылка ImageStore; удаление поля/шаблона учитывается в refcount.
- Приёмка каждого нового типа — фиксированный набор тестов.
- CHANGELOG: незавершённое, поверх A1.

Не входит: undo, duplicate, snap, z-order, copy-paste (A-editor); PDF; пресеты; экземпляр персонажа; хост.

## Capabilities

### New Capabilities

- (нет)

### Modified Capabilities

- `character-sheet-storage`: схема v2, много страниц с именами, новые типы полей в JSON, чтение v1, отказ на неизвестный тип; создание по-прежнему одна пустая страница (теперь v2).
- `character-sheet-editor`: лента страниц + рейка, смена колеса, вписать ширину, ориентация, перенос поля между страницами, палитра и свойства новых типов, даблклик картинки/чекбокса.
- `image-storage`: поля чар-листа ссылаются на `images`; конвейер выбора файла из редактора листа; GC/refcount при снятии картинки, удалении поля и удалении шаблона.

## Impact

- Domain: `FieldType` расширяется; clamp по странице и сцена-лента (Y-смещение страниц); парсер v1→v2.
- ViewModel/views: рейка, многостраничная сцена, палитра, свойства per-type, ImageStore в редакторе.
- `CharacterSheetService`: load v1/v2, отказ unknown type, delete шаблона гоняет GC картинок.
- ImageStore: подсчёт ссылок с полей `pages` JSON (не только FK сущностей).
- Тесты: пер-тип виджеты + round-trip + ориентация + лента/рейка + ImageStore ref; E2E много страниц.
- `docs/CHANGELOG.md`, `docs/character-sheets-roadmap.md` (статус куска).
- Без новых runtime-зависимостей.
