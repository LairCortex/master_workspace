## ADDED Requirements

### Requirement: Создать из пресета

На вкладке «Шаблоны» SHALL быть действие «Создать из пресета…». Оно SHALL открывать диалог: список пресетов, лицензионный текст выбранного, поле имени. Подтверждение с свободным именем SHALL создать шаблон-снимок и открыть его Design без несохранённых правок. Отмена SHALL не создавать шаблон. Пока Design открыт на другом шаблоне с грязным макетом, создание из пресета SHALL сначала спросить, как при открытии другого шаблона.

#### Scenario: Кнопка на вкладке шаблонов

- **WHEN** открыта вкладка «Шаблоны»
- **THEN** доступно действие «Создать из пресета…»

#### Scenario: Успех открывает чистый Design

- **WHEN** пользователь подтверждает создание из пресета со свободным именем
- **THEN** открывается Design нового шаблона, dirty снят, на канвасе макет пресета

#### Scenario: Отмена

- **WHEN** пользователь открывает диалог пресета и отменяет
- **THEN** новый шаблон в базе не появляется

## MODIFIED Requirements

### Requirement: Вкладки Шаблоны и Листы

Пункт меню «Чар-листы» SHALL открывать список с вкладками «Шаблоны» и «Листы». Вкладка «Шаблоны» SHALL сохранять создание, открытие, переименование, удаление шаблонов и создание из пресета. Вкладка «Листы» SHALL давать создание, открытие, переименование и удаление заполненных листов. Создание листа SHALL требовать выбора шаблона и имени; после успешного создания SHALL открываться Fill этого листа без несохранённых правок.

#### Scenario: Вкладка листов

- **WHEN** пользователь открывает «Чар-листы» и выбирает вкладку «Листы»
- **THEN** виден список заполненных листов текущей игры

#### Scenario: Создание открывает чистый Fill

- **WHEN** пользователь создаёт лист со свободным именем и существующим шаблоном
- **THEN** открывается Fill этого листа, канвас показывает сохранённый шаблон со значениями по умолчанию, dirty снят

#### Scenario: Пресет с вкладки шаблонов

- **WHEN** пользователь на вкладке «Шаблоны» выбирает «Создать из пресета…»
- **THEN** открывается диалог пресетов, вкладка «Листы» это действие не содержит
