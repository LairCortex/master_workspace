# Proposal: add-character-sheet-c

## Why

После B мастер может нарисовать шаблон и заполнить экземпляр, но в пустой игре нет ни одного играбельного листа системы. C даёт каталог пресетов и два своих одностраничных макета (Fate Core, Mörk Borg): копия в `game.db`, дальше обычный шаблон. Без этого хост (D1) раздаёт пустоту.

Зависит от [`add-character-sheet-a1`](../add-character-sheet-a1/), [`add-character-sheet-a-playable`](../add-character-sheet-a-playable/), [`add-character-sheet-a-editor`](../add-character-sheet-a-editor/), [`add-character-sheet-b`](../add-character-sheet-b/) (применять пятым).

## What Changes

- Вкладка «Шаблоны»: «Создать из пресета…». Диалог показывает **только** Fate Core и Mörk Borg и полный лицензионный текст выбранного.
- Имя спрашивается, подстановка — имя пресета; конфликт как у обычного шаблона. INSERT снимка (`schema_version` 2) → открыть Design, dirty снят.
- После копии шаблон не связан с бандлом: правка и удаление как у любого шаблона; обновление приложения уже скопированное не переписывает.
- Макеты **свои**, русские подписи, одна книжная A4, пустой портрет, без файлов картинок и без логотипов издателей. Не импорт Anima и не трассировка официального PDF.
- Fate Core: аспекты, 18 навыков числами, стресс, последствия, трюки; на листе CC BY Evil Hat.
- Mörk Borg: характеристики, HP, серебро, знамения, оружие/броня; на листе обязательный абзац 3PP.

Не входит: остальные системы (C2+), таблица/радио/repeating, авто-вставка в новую игру, сброс к бандлу, PDF, хост.

## Capabilities

### New Capabilities

- `character-sheet-preset`: каталог бандл-пресетов, снимок в игру, лицензионные тексты, состав полей Fate Core и Mörk Borg.

### Modified Capabilities

- `character-sheet-editor`: на вкладке «Шаблоны» действие «Создать из пресета…», диалог выбора и имени, открытие Design после INSERT.

## Impact

- Бандл: JSON макетов v2 в данных приложения + `nri_manager.spec` `datas`.
- Сервис: `list_presets` / `create_from_preset` через существующий INSERT шаблона.
- Список шаблонов: кнопка и диалог; лицензия в диалоге и label на канвасе.
- Тесты: каталог из двух, копирование, конфликт имени, лицензионные строки, состав полей, dirty=false после открытия. Без сети.
- `docs/CHANGELOG.md`, `docs/character-sheets-roadmap.md`.
- Без новых runtime-зависимостей. `schema_version` шаблона остаётся 2. ALTER не нужен.
