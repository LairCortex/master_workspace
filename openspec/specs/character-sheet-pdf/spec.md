# character-sheet-pdf Specification

## Purpose

Выгрузка текущего макета шаблона чар-листа в fillable PDF для бумаги и правки в Acrobat/Preview. Импорта PDF обратно в игру нет.

## Requirements

### Requirement: Страницы и масштаб

Система SHALL писать по одной странице PDF на каждую страницу шаблона в том же порядке. Размер страницы PDF SHALL быть A4 в ориентации шаблона. Зазор ленты канваса SHALL не попадать в файл. Геометрия SHALL быть 1:1 в пунктах относительно макета; масштаб окна Design SHALL не влиять.

#### Scenario: Две страницы

- **WHEN** у шаблона две страницы и пользователь экспортирует PDF
- **THEN** в файле две страницы A4 в порядке шаблона, без третьей и без полосы-зазора

#### Scenario: Альбомная

- **WHEN** ориентация шаблона альбомная
- **THEN** каждая страница PDF альбомная A4

#### Scenario: Зум не меняет лист

- **WHEN** в Design лист увеличен и пользователь экспортирует
- **THEN** размер страницы PDF тот же, что у незумированного A4 шаблона

### Requirement: Виджеты AcroForm

Поля типов text, textarea, checkbox, number и dropdown SHALL быть редактируемыми полями формы. Имя поля формы SHALL совпадать с `id` поля шаблона. Начальное значение SHALL быть тем, что сейчас в макете (строка / «true»|«false» / выбранный пункт списка), в том числе пустое. Number SHALL быть текстовым полем без проверки min/max. Dropdown SHALL предлагать опции шаблона; произвольный ввод не цель. Скрипты в PDF SHALL не встраиваться.

#### Scenario: Текст и область

- **WHEN** на листе однострочное поле с текстом «Имя» и многострочное с «Предыстория»
- **THEN** в PDF есть два редактируемых текстовых поля с этими значениями; многострочное принимает несколько строк

#### Scenario: Чекбокс и список

- **WHEN** чекбокс включён по умолчанию и у списка опции «А», «Б» с выбранным «Б»
- **THEN** в PDF чекбокс отмечен, список содержит «А» и «Б», выбрано «Б»

#### Scenario: Число без формулы

- **WHEN** числовое поле с содержимым «3.5» и заданными min/max
- **THEN** в PDF это редактируемая строка «3.5»; файл не содержит скрипта проверки границ

### Requirement: Рисунок без виджета

Поля label, rect, line и image SHALL быть рисунком, не полями формы. Подпись SHALL показывать свой текст. Рамка и линия SHALL совпадать с геометрией макета. Картинка SHALL рисовать битмап из хранилища игры, если файл читается; иначе пустую рамку того же размера. Отсутствие или порча файла картинки SHALL не отменять экспорт остальных страниц и полей. Image SHALL не быть полем формы: в PDF-редакторе портрет нельзя заменить виджетом.

#### Scenario: Подпись и рамка

- **WHEN** на листе подпись «Сила» и декоративная рамка
- **THEN** в PDF виден текст «Сила» и прямоугольник рамки; отдельного поля формы для них нет

#### Scenario: Картинка на месте

- **WHEN** у поля-картинки есть читаемый файл в хранилище
- **THEN** на странице PDF в рамке поля видно это изображение, поля формы с этим `id` нет

#### Scenario: Битая картинка

- **WHEN** у поля-картинки ссылка на отсутствующий файл и на листе есть текстовое поле
- **THEN** файл PDF создаётся, на месте картинки пустая рамка, текстовое поле на месте
