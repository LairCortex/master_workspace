# dnd-character-export Specification

## Purpose

Сборщик документа персонажа в формате Long Story Short (`character.json` v2) из текущего состояния карточки и выгрузка его мастеру для импорта в LSS. Дверь служит и мастеру («Экспорт для LSS…»), и дозаполнению генерацией: документ всегда отражает карточку, а не застаревший сырой файл.

## Requirements

### Requirement: Сборка документа из текущего состояния карточки

Приложение SHALL собирать документ `jsonType: "character"`, `version: "2"`, с `data` — JSON-строкой по схеме формата, из текущего состояния карточки персонажа: имя, уровень, привязки вида/подвида/класса/подкласса/предыстории идентификаторами подключённых источников со снимками имён, текстовые блоки, привязки заклинаний слагами. Собранная форма SHALL проходить существующий валидатор документа персонажа без ошибок. Привязка с недоступным источником SHALL принимать единственную форму: в документ она НЕ попадает (слаговый ключ опускается), снимок имени сохраняется в карточке и в текстовых частях документа; второго вида «помеченная привязка» не вводится. Числовые механические поля сборщик SHALL NOT выдумывать: что не задано в карточке, в документ не попадает.

#### Scenario: Документ следует за карточкой

- **WHEN** после импорта мастер поправил описание и сменил уровень, и документ собран заново
- **THEN** документ отражает правки карточки, а не содержимое сохранённого сырого файла

#### Scenario: Пустые поля не выдумываются

- **WHEN** в карточке не заданы уровень и часть привязок
- **THEN** соответствующие поля документа отсутствуют или пусты, ошибок валидатора нет

#### Scenario: Снятый датасет не калечит документ

- **WHEN** привязка ссылается на отключённый источник
- **THEN** сборка не падает: снимок имени сохранён, слаговый ключ этой привязки в документе отсутствует, валидатор ошибок не показывает

### Requirement: Кнопка «Экспорт для LSS…»

В D&D-табе карточки персонажа при включённом модуле SHALL быть кнопка «Экспорт для LSS…», сохраняющая собранный документ в выбранный мастером файл. Кнопка SHALL быть доступна без настроенного AI-ассистента — экспорт не обращается к сети. Дозаполненного или импортированного персонажа кнопка экспортит наравне с рукотворным.

#### Scenario: Экспорт рукотворного персонажа

- **WHEN** мастер создавал персонажа только карточкой (без импорта) и нажал «Экспорт для LSS…»
- **THEN** сохранённый файл проходит валидатор документа персонажа без ошибок

#### Scenario: Экспорт без AI

- **WHEN** ассистент не настроен
- **THEN** кнопка активна и экспорт выполняется

#### Scenario: Сохранение отменено

- **WHEN** мастер отменил диалог выбора файла
- **THEN** ни файл на диске, ни карточка, ни сырой файл персонажа не изменены

### Requirement: Совместимость экспорта с приёмом LSS

Экспортируемый документ SHALL быть самодостаточен для импорта средствами LSS: конверт-гейты формата (jsonType, версия, структура `data`) проходят, текстовые блоки строятся узлами форматированного редактора формата (не HTML, без `blockquote`), формулы — латиницей заглавными переменными.

#### Scenario: Файл проходит гейты формата

- **WHEN** экспорт любого персонажа выполнен
- **THEN** файл проходит проверку конверта и схемы `data` без ошибок, текстовые блоки — валидные узлы форматированного редактора
